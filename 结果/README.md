# 结果目录

当前结果只保留两个业务视图：

| 目录 | 作用 | 首选入口 |
|---|---|---|
| `可用数据集/` | 冻结的Gold-V/C/E基础长表、曲线索引和字段字典 | [可用数据集说明](可用数据集/README.md) |
| `定向筛选/` | 当前三目标标签、67个扩充包、现实候选和代理训练入口 | [定向筛选说明](定向筛选/README.md) |

不要从文件数量推断材料数。优先读取：

- `定向筛选/代理训练任务统计.csv`：训练规模；
- `定向筛选/扩充数据总账.csv`：包级目录；
- `定向筛选/多目标材料索引.csv`：材料级覆盖；
- `定向筛选/发布清单.json`与各来源发布清单：哈希和数量门。

旧Excel审计附件保存在本地`数据/原始/历史审计附件/`，不进入GitHub。大型原始文件、计算运行目录和模型权重均不放在`结果/`根目录。
