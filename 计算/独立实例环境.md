## 烟雾测试

使用一个二醇扩链剂和一个二异氰酸酯，按正式命令以1线程并行执行：

```bash
xtb conformer.xyz \
  --sp --gfn 2 --chrg 0 --uhf 0 \
  --acc 0.5 --iterations 500 --etemp 300 \
  --pop --dipole --wbo --json --norestart -P 1
```

两个任务均退出码0，日志末行为`normal termination of xtb`，并生成`xtbout.json`、`wbo`、`charges`、`xtbtopo.mol`。真实6.7.1单点不生成`.xtbok`，因此项目成功门已依据烟雾结果修正为：退出码0、日志正常终止、无`.sccnotconverged`、JSON/WBO及字段闭合。

| 构件 | HOMO/LUMO gap (eV) | 偶极矩 (D) | GFN2/D4 α(0) (au) | 电荷和误差 |
|---|---:|---:|---:|---:|
| 二醇扩链剂 | 11.0465 | 2.9866 | 60.9122 | `1.0e-8 e` |
| 二异氰酸酯 | 4.6700 | 3.7176 | 104.2603 | `1.0e-17 e` |

JSON中的完整版本字符串为`6.7.1 (edcfbbe)`；解析器保存完整字符串，同时严格要求主版本6.7.1。WBO、逐原子电荷、分子及逐原子`α(0)`均成功解析。NCO/OH双位点、元素顺序、SASA和非键接净间隙烟雾测试也通过。

- CUDA运行时：13.0；
- GPU：NVIDIA L40；
- RDKit：2026.03.5；Pandas：2.3.3；NumPy：2.5.2；
- GPU矩阵乘法烟雾测试：通过；
- GNN数据、模型和训练联合测试：52项通过，1项“缺少PyTorch”错误路径测试按设计跳过。

训练命令使用下列显式搜索路径，不修改现有语音或TPU虚拟环境本身：

```bash

  --数据 结果/可用数据集/计算观测.csv.gz \

```
