# 现实构件量化输入

本目录保存现实库19个商业构件/产品代表的构件级CREST/xTB输入准备，不包含完整TPU链或块体MD。

- 7个二异氰酸酯和7个扩链剂/商业混合物连接度代表全部成功生成；
- PTMG-650/1000/1400/1800/2000分别建立羟基封端单链代表；
- 19/19个任务成功嵌入，16个MMFF94s收敛；
- PTMG-1000、PTMG-1800、PTMG-2000在MMFF94s的1000步内未收敛，随后已在Ubuntu以8线程GFN-FF完成几何预优化并通过日志/输出哈希核验。

`量化任务.csv`保存SMILES、模型边界、构象数、力场状态、原始/预优化XYZ路径和哈希。`预优化/预优化清单.json`保存3条GFN-FF结果血缘；`发布清单.json`保存输入哈希、聚合几何哈希、计数和解释限制。当前19个任务均已通过下一阶段几何输入门。

PTMG代表只用于计算方法和链长代理比较。商业PTMG仍是具有OH值、水分、Mn/Mw/PDI和批次分布的产品，不能用这一个结构代替真实分布。
