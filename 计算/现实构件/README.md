# 现实构件量化输入

本目录保存现实库7个商业构件的构件级CREST/xTB输入准备，不包含完整TPU链或块体MD。

- 4,4'-MDI、IPDI、H12MDI、HDI和1,4-BDO：RDKit ETKDGv3生成10个初始构象，MMFF94s最低能结构收敛；
- PTMG-1000单链代表：14个四亚甲基醚重复单元、185个含氢原子；
- PTMG-2000单链代表：27个重复单元、354个含氢原子；
- 两个PTMG代表成功嵌入，但MMFF94s在1000步内未收敛，必须先做xTB几何预优化，不能直接与5个小分子同等进入CREST。

`量化任务.csv`保存SMILES、模型边界、构象数、力场状态、XYZ路径和哈希。`发布清单.json`保存输入哈希、聚合几何哈希、计数和解释限制。

PTMG代表只用于计算方法和链长代理比较。商业PTMG仍是具有OH值、水分、Mn/Mw/PDI和批次分布的产品，不能用这一个结构代替真实分布。
