本目录保存当前虚拟构件计算库的紧凑、可复核输出，不保存30,647个xTB结果包或大体积CREST轨迹。现实可采购配方使用`结果/现实筛选`，两条路线不得混为同一真值层。

## 文件

- `虚拟构件xTB系综描述符.csv`：83行构件级Boltzmann代理聚合描述符，是本目录其他筛选表的直接计算输入。
- `阶段配方特征.csv`：保留全部48条配方及三类构件连接状态、阶段目标、聚类和闭门原因。
- `阶段Pareto候选.csv`：仅含28条当前非支配配方；它不是宏观力学性能排名。
- `阶段筛选报告.md`：目标方向、标准化参数和使用边界。
- `xTB阶段描述符清单.json`：父版本、增量任务、软件哈希、行数和输出哈希。
- `xTB重复性验证.json`：任务85的22构象独立复算；构象级最大数值差`4.87×10^-11`，构件级最大差`3.02×10^-10`，通过声明阈值。

## 使用方法

本阶段只能用于构件级反应位点电荷、可及性、构象不确定度和计算负担的比较。训练时应标为计算来源/低保真辅助特征，不能标作拉伸强度、断裂伸长率、韧性、Tg或可合成性实验真值。

重新生成筛选表时使用仓库根目录下的任务队列、当前构件系综表和`代码/生成阶段配方筛选.py`。完整84构件发布必须等任务84通过终态与哈希门后重新计算标准化参数、聚类和Pareto前沿；不得把阶段83文件简单改名为最终版。

方法依据与正式引用见[数据来源与参考文献](../../文档/数据来源与参考文献.md)中的GFN2-xTB与CREST条目[177]、[178]和[180]；实时科学边界见[当前数据状态](../../文档/当前数据状态.md)。
