# 原始数据层

本层保存下载或克隆得到的不可变来源文件。管道只读访问，不在原位置清洗、改名或覆盖第三方数据集内部文件。

- `基础数据/`：OpenPoly、PI1M、SMiPoly 和早期需求工作簿。
- `外部数据/`：论文附件、开放仓库数据和力学曲线。
- `代码仓库镜像/`：带固定提交哈希的第三方 Git 仓库。
- `仅供参考/`：许可证、材料定义或数据完整性不允许进入发布训练集的来源。

原始文件不进入 GitHub。`配置/清单/来源清单.csv` 只保存旧 v0.1 四源管道的兼容快照；v0.2 来源身份与资产规则分别维护在 `配置/v0.2来源范围.yaml` 和 `配置/v0.2资产登记规则.yaml`，进入当前总账的输入路径、字节数和 SHA-256 写入 `结果/数据总账.json`。没有明确来源、许可和用途的原件默认禁止发布。
