# 原始数据层

本层保存下载或克隆得到的不可变来源文件。管道只读访问，不在原位置清洗、改名或覆盖第三方数据集内部文件。

- `基础数据/`：OpenPoly、PI1M、SMiPoly 和早期需求工作簿。
- `外部数据/`：论文附件、开放仓库数据和力学曲线。
- `代码仓库镜像/`：带固定提交哈希的第三方 Git 仓库。
- `仅供参考/`：许可证、材料定义或数据完整性不允许进入发布训练集的来源。

原始文件不进入 GitHub；文件路径、字节数和 SHA-256 写入 `配置/清单/来源清单.csv`。只有逐来源登记的文件才补充 DOI/URL、许可证、访问限制和用途；未登记文件默认禁止发布。
