# 现实库机器学习适用域说明

现有GNN使用Gold-C中26,176条单结构计算观测训练，结构身份主要是聚合物重复单元或计算结构。现实库则由“二异氰酸酯+商业宏二醇牌号+扩链剂+配比”组成，两者表示层级不同。

以Morgan radius 2、2048 bit最大Tanimoto作保守诊断：

- 5个PTMG单链代表：相似度0.464，处于训练结构域边界；
- 14个离散商业构件：最大相似度0.138–0.382，均处于当前训练结构域外；
- 980条现实配方的三构件相似度下限均低于0.40，因此全部标记`blocked_component_outside_training_domain`；
- 所有配方的`ml_prediction_status`保持`blocked_pending_multicomponent_formulation_model`。

这个结果不能解释为商业原料“性能差”或“化学不合理”。它只说明旧GNN的输入是单一结构，不能代表现实TPU配方。下一版模型必须显式编码：

```text
二异氰酸酯图
+ 宏二醇家族/代表链/Mn/Mw/PDI/OH值
+ 扩链剂图
+ NCO/OH、硬段比例
+ 催化剂、含水量、温度、时间和加工方式
```

合理架构是三个构件编码器、配方/工艺数值分支和多保真任务头；先在虚拟库预训练构件表示，再用闭合实验配方校准。构件CREST/xTB描述符完成后可作为额外输入，但不能替代真实配方标签。

机器可读结果：`构件适用域.csv`、`配方适用域.csv`和`适用域运行清单.json`。
