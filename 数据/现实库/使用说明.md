# 双库筛选流水线使用说明

## 重建双库视图

```powershell
uv run python .\代码\构建双库.py
```

该命令仅读取现有Gold发布、商业构件证据和配方，不修改Gold文件。`数据/双库发布清单.json`记录输入/输出哈希、行数和虚拟到现实的泄漏计数。

## 一贯流程

```text
虚拟库：全部实验/模拟/虚拟结构
  -> 表征学习、GNN/Ridge、多任务与不确定度

现实库：商业证据构件
  -> 真实产品级配方组合
  -> ML适用域和代理筛选
  -> 构件CREST/xTB
  -> 少量配方/反应片段DFT
  -> 真实PTMG低聚链与扩链后的TPU链
  -> 无定形/微相模型MD
  -> 性能、可合成性、采购、EHS和不确定度Pareto
  -> 小规模真实合成
```

虚拟库只能向现实库提供模型和候选建议，不能直接传递“可购买”或“实验就绪”状态。现实库配方反过来产生的实验结果可以回写Gold-E，从而校准模型。

## 当前阶段门

- `component_crest_xtb`：5个离散商业原料，可以开始三维结构和构件级量化准备；
- `macrodiol_representative_crest_xtb`：2个PTMG单一低聚链代表，可以用于方法比较，但不得解释为产品分布；
- `formulation_dft`：等待构件描述符和反应后片段；
- `bulk_md`：等待扩链后TPU链、力场、电荷、密度和链长协议；
- `ml_status`：等待能表示二异氰酸酯+真实宏二醇+扩链剂+配比/工艺的配方模型。

现有GNN只学习重复单元/结构对应的计算性质，不能直接给现实配方填充强度或韧性。后续模型必须显式消费三个构件、Mn/Mw/PDI、NCO/OH、硬段和工艺字段。
