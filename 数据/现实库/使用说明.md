# 双库筛选流水线使用说明

## 重建双库视图

```powershell
uv run python .\代码\构建双库.py
```

该命令仅读取现有Gold发布、商业构件证据和配方，不修改Gold文件。`数据/双库发布清单.json`记录输入/输出哈希、行数和虚拟到现实的泄漏计数。

## 一贯流程

```text
虚拟库：全部实验/模拟/虚拟结构
  -> 表征学习、GNN/Ridge、多任务与不确定度

现实库：商业证据构件
  -> 真实产品级配方组合
  -> ML适用域和代理筛选
  -> 构件CREST/xTB
  -> 少量配方/反应片段DFT
  -> 真实PTMG低聚链与扩链后的TPU链
  -> 无定形/微相模型MD
  -> 性能、可合成性、采购、EHS和不确定度Pareto
  -> 小规模真实合成
```

虚拟库只能向现实库提供模型和候选建议，不能直接传递“可购买”或“实验就绪”状态。现实库配方反过来产生的实验结果可以回写Gold-E，从而校准模型。

## 重建现实量化与首轮筛选

```powershell
uv run python .\代码\生成PTMG代表链段xTB任务.py `
  --xTB二进制SHA256 debf27a9e0fa4bfb5ca75aafe4b90d8211f08ec2f4a482f375a4987212eaa12a

uv run python .\代码\生成现实配方量化表.py
uv run python .\代码\生成现实首轮筛选.py
```

三个命令依次生成5个PTMG代表任务、19构件/980配方混合保真度量化表，以及Pareto前沿和40条DFT/MD复核队列。生产xTB结果必须先从授权计算实例按发布清单回填；脚本不会用缺失值、相似构件或GNN预测静默补齐失败任务。

首轮筛选的五个目标是NCO/OH位点电荷互补、三角色位点可达性下限、三角色HOMO-LUMO能隙下限、离散构件构象不确定度和离散构件构象负担。它们是量化代理，不是强度、韧性、循环恢复或最终性能。40条队列强制覆盖全部7个二异氰酸酯、5个PTMG和7个扩链剂，并限制单一构件在队列中的占比；队列仍需经过采购、SDS、EHS、文献新颖性及后续DFT/MD门。
