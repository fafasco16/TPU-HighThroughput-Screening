# TPU现实库

现实库只包含具有明确商业证据和聚氨酯角色的原料及其配方。当前第一版包含：

- 4个二异氰酸酯：4,4'-MDI、IPDI、H12MDI、HDI；
- 2个真实商业宏二醇牌号：PTMG-1000、PTMG-2000；
- 1个扩链剂：1,4-BDO；
- 8个化学体系和32条硬段/NCO-OH网格配方；
- 4条第一轮小型商业对照矩阵。

文件：

- `构件.csv`：现实构件身份、牌号和实验释放状态；
- `配方.csv`：只引用现实构件ID的配方；
- `来源与证据.csv`：制造商页面、CAS/牌号和检索日期；
- `PTMG代表模型.csv`：用于计算的单一低聚链代表，明确不代表商业产品分布；
- `计算任务.csv`：构件、PTMG代表、配方DFT和块体MD的依赖任务；
- `筛选队列.csv`：ML/DFT/MD阶段门和下一动作。

现实库中的“可行”仍只表示可以进入实验规划。询价、国内库存、COA、SDS、本单位EHS和具体工艺审核完成前，全部保持`blocked_pending_quote_sds_and_local_approval`。
