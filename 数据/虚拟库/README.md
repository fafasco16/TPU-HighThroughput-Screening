# TPU虚拟库

虚拟库包含项目收集的全部实验、计算、结构候选、虚拟组合和模型结果。它的目标是覆盖化学空间、训练表征和机器学习模型，不要求每个结构都能采购或直接合成。

本目录不复制数十万至百万行的冻结数据，只保存[资产索引](资产索引.csv)。索引中的路径和SHA-256指向现有唯一事实文件，避免仓库再次出现重复数据和多份版本。

虚拟库允许：

- Gold-C计算数据用于预训练、低保真目标和多任务学习；
- Gold-E实验数据用于校准和外部验证；
- Gold-V、SMiPoly、PolyUniverse和虚拟组合用于表示学习、聚类及主动学习；
- 陌生或不可购买结构用于扩大模型适用域；
- CREST/xTB和GNN结果用于方法开发与不确定度分析。

虚拟库不允许直接产生采购单或实验释放结论。任何结构进入真实合成前都必须在现实库重新通过身份、商业证据、宏二醇产品身份、计量、SDS和EHS门。
