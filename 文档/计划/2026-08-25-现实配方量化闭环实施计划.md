# 现实配方量化闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已完成的商业构件 CREST/xTB 结果和五个 PTMG 牌号的受限代表链段计算，闭合为 980 条可审计、可用于首轮多目标筛选的现实配方描述符表。

**Architecture:** 原始虚拟库和现实商业库继续隔离。远端量化产物只通过 SHA-256 发布清单进入本地；离散构件使用 CREST 系综加权描述符，PTMG 使用明确标注的单代表链段 xTB 代理，二者的保真度和允许用途分别记录。配方只通过稳定构件 ID 连接，任何缺失、失败、身份不符或代理范围越界都关闭对应筛选资格。

**Tech Stack:** Python 3.11/3.12、pandas、RDKit、CREST 3.0.2、xTB 6.7.1、pytest、CSV/JSON/SHA-256。
