## 1. 结论先行

本轮已经把“数据太少”拆成两个不同问题，并分别处理：

1. **物理资产量已经不小。** 当前新增开放数据层包含 23 个来源目录、6,604 个本地文件、1,914,408,449 字节。这个数包含官方压缩包、只读解包副本、元数据、图像和审计清单，不能直接解释为科学样本数。
2. **真正稀缺的是独立、可追溯、配方身份完整的 TPU/TPUU 实验单元。** 曲线点、模拟帧、仪器模板、同一试样的循环、压缩包与解包副本都不能扩大化学空间。
3. **模拟数据正式纳入多保真数据库。** DFT、AIMD、经典 MD/轨迹、计算描述符和虚拟候选分别登记；只有计算输出、方法、体系、协议和收敛闭合，且完成实验映射时，才可作为主要计算观测。未映射但可审计的 DFT 只能作为低权重跨尺度描述符；模拟输入、代码、未收敛结果和模型预测默认不是真值。
4. **最值得优先投入的主路线是“核心 TPU/TPUU 实验 + 机理计算 + 工艺/应用迁移”。** DRUM 两套可化学回收 TPUU、QUB 生物基自愈 TPU 和既有线性 TPU 数据构成核心实验层；DFT 封端剂、硬段 AIMD/MD 构成跨尺度机理层；SLS、TPMS、热电复合、泡沫与器件数据只做条件迁移或外部验证。
5. **本轮只冻结准入规则和未来权重边界，不启动训练。** 具体规则见[`v0.2多保真准入与权重策略.yaml`](../../配置/v0.2多保真准入与权重策略.yaml)。

## 2. “样本数”必须按科学层级报告

数据库对以下单位分别计数，论文中不得互相替代：

| 层级 | 正确含义 | 常见错误 |
|---|---|---|
| 来源/研究 | 一个 DOI、论文或独立实验项目 | 把同一研究的论文、数据集和代码算成三个独立研究 |
| 配方/材料 | 单体、当量、软硬段、扩链剂和添加物定义的材料 | 把一个商业牌号的多个试样算成多个配方 |
| 合成批次 | 独立制备的一批材料 | 没有批次号时随机拆分同配方数据 |
| 物理试样 | 实际接受测试的一件试样 | 把循环、温度扫描或不同导出文件算成新试样 |
| 曲线/采集 | 一次可定位的测试序列 | 把重采样、平滑或复制到另一图表的曲线算成新曲线 |
| 曲线点/模拟帧 | 同一曲线或轨迹内的相关观测 | 把几十万点或几百万帧当作独立训练样本 |
| 派生指标 | 由原始曲线积分、拟合或汇总得到的量 | 与原曲线重复监督而不保留派生血缘 |

因此，本轮虽然新增超过百万个曲线点和数值单元，但真正决定化学泛化能力的是配方、批次与独立试样，而不是行数。

## 4. 为什么以前“那么多数据”没有直接入选

没有入选不等于没有价值。主要原因分为八类：

1. **同一化学体系的重复非常多。** SLS 的 350 个试样仍只有一个商业 TPU；老化泡沫的 90 个试样仍是一个未知配方。
2. **曲线点不是独立样本。** 779,948 个拉伸、滞回及 DMTA 点属于 158 个试样，不能随机拆点训练和验证。
3. **物理镜像不增加科学信息。** TPU95A 新目录的 12 个 CSV 与既有目录逐字节相同，增量样本为零。
4. **配方身份不足。** 商业牌号、泡沫、器件基底和复合物往往缺少单体、当量、分子量、NCO/OH、催化剂、含水量和批次。
5. **材料域不一致。** 热固 PU、微孔泡沫、纤维、复合材料和共轭氨基甲酸酯玻璃体可以迁移，但不能以数量优势主导线性 TPU 终性能。
6. **许可或访问证据未闭合。** Bath 未声明原始文件复用许可证；AGH 主文件需要申请；ScienceDB TPU/ANF 为 CC BY-NC 4.0，商业用途必须阻断。
7. **字段和单位冲突。** 未声明的吸能单位、乱码表头、模量/韧性量级冲突或缺失几何转换都必须暂缓对应标签。
8. **输入、代码、图像和模型输出不是目标真值。** 它们对复现、表示学习和审计有价值，但不能自动生成宏观性能标签。

这些排除与降权规则保护了论文的可信度。把所有行直接合并会得到更大的表，却会引入同源泄漏、伪重复、单位错误和域偏移。

## 5. 多保真权重策略

未来权重采用以下结构，当前只冻结规则，不计算权重：

\[
W_{obs}=I_{\mathrm{hard\_gate}}W_{\mathrm{effective\_ceiling}}q_{evidence}q_{target}q_{mapping}q_{independence}
\]

- `I_hard_gate`：权利、解析、单位、收敛、血缘或范围任一硬门失败时为 0。
- `W_effective_ceiling`：按任务特定来源上限、来源上限、默认保真带依次解析的最具体上限。
- `q_evidence`：Q1 至 Q5；Q5 为 0。
- `q_target`：同一 QoI 为 1，校准跨尺度描述符降权，越界任务为 0。
- `q_mapping`：试样直接观测最高；只有研究级映射或无可审计映射时显著降权或为 0。
- `q_independence`：独立试样可以提高统计精度但不扩大化学空间；同一试样循环先在组内归一，重采样或派生副本不重复放大。

`W_effective_ceiling` 按“任务特定来源上限 → 来源上限 → 默认保真带”依次解析。例如 TPU/SWCNT 在热电任务可用 0.60 上限，但在纯 TPU 力学任务只能用 0.20；默认带的下端不是强制权重地板。独立 dogbone 可增加重复证据，仍必须跟随同一配方/批次分组；是否做来源平衡和配方上限只在预注册的消融与有效样本量审计后确定，当前不武断固定为每个配方总权重 1。

默认带为：核心 TPU 原始实验 0.80–1.00；核心发表汇总 0.45–0.65；实验迁移 0.15–0.35；已校准 DFT 0.30–0.50；未映射 DFT 0.10–0.25；已验证 MD/AIMD 0.20–0.40；虚拟候选 0–0.15；模型预测、模拟输入和代码为 0。

机器可读的 `配置/v0.2多保真准入与权重策略.yaml` 是权重上限、硬门与拆分语义的唯一权威来源。来源级早期审计中的启发式建议不得与统一策略并列作为第二套权重事实；本轮已按原摘要 SHA-256 对 DFT 解封剂、植物基泡沫和可打印复合 PU 三份摘要做确定性策略对齐，并保留“当前未训练、未拆分、未物化权重”的状态。

这里的“上限”不是预先决定的最终权重。正式物化前仍需按目标性质、适用域、证据等级和留出设计做敏感性分析。

## 6. 防止数据泄漏

最低分组顺序为：

`source_family → study/DOI → synthesis_batch → formulation → specimen → curve/trajectory`

必须执行：

- 同一配方的多个 dogbone 不跨训练/验证；
- 同一试样的循环、平滑、DIC、机器曲线和派生指标同折；
- 原始压缩包、解包副本、镜像仓库和派生表不跨折；
- 同一计算体系的不同帧同折；只有独立种子且重新平衡的轨迹才可能构成独立计算重复；
- 论文、数据集和代码属于同一研究家族时按同一研究留出；
- 最严格的外部验证按整篇研究/整 DOI 留出。

## 8. 值得继续推进的数据路线

### 路线 A：可回收/自愈 TPUU 的结构—耗散—回收闭环（首选）

以 DRUM 两套 TPUU 和 QUB TPU 为核心，结合既有 Eom、Pugar、PUE 曲线与实验合成。关键不是单纯追求最高强度，而是同时预测/验证：完整应力—应变与韧性、循环滞回、恢复、加工窗口、解聚或再聚合可行性。该路线已有高质量开放数据，但不同研究的化学空间尚未统一，仍有形成新体系与实验验证的空间。

### 路线 B：DFT/AIMD/MD 机理描述符辅助小样本筛选（与 A 融合）

用封端剂 DFT 数据建立键能—解封温度映射，用硬段量化/AIMD刻画异氰酸酯骨架与氢键网络；后续再针对候选 TPU 做经典 MD 的相分离、氢键寿命、链段运动和密度/Tg 代理。计算层只提供可解释描述符和候选排序，最终性能仍由真实合成与实验曲线验证。

### 路线 C：工艺与应用作为硬门槛，而非化学主模型

SLS、TPMS、导电轨迹、TPU/SWCNT、泡沫冲击和纤维数据用于回答候选是否具有可打印性、速率稳定性、循环可靠性和应用价值。它们适合多任务辅助或外部验证，不应改变主模型的化学域。

当前推荐组合是 **A + B，以 C 作实验应用验证**。这比把所有来源平铺成一张表更符合一区论文需要的机理、新颖性、可复现性和真实验证闭环。

## 9. 进入训练前仍必须完成的门槛

1. 冻结目标性质定义、单位和曲线派生算法；
2. 物化配方—批次—试样—曲线—点及计算体系—协议—种子血缘；
3. 完成所有精确重复、镜像、派生与化学等价组；
4. 对配方未知、单位冲突、许可未明和访问受限来源保持阻断；
5. 按研究/配方/批次生成分组留出方案；
6. 预注册权重敏感性分析：实验单保真、实验+DFT、实验+DFT+MD、加入迁移层四组对照；
7. 为最终实验预留完全未参与模型选择的新化学体系；
8. 只有上述门槛闭合后，才创建训练视图和物化权重。
