# 本地审计与QUB生物基自修复TPU扩库实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不混淆样本数、曲线点数和材料数的前提下，审计当前本地库，并将QUB开放的生物基自修复TPU原始数据物化为可复现、可追溯、可分组训练的韧性、循环恢复和热稳定数据包。

**Architecture:** 原始CSV保持只读；新适配器直接解析原始应力—应变、循环和TGA曲线，并以来源DOI与配方作为泄漏分组键。端点、曲线和发布清单独立输出，再由多目标材料索引和扩充数据总账统一汇总；Zenodo乙烯基氨基甲酸酯玻璃体只保留在迁移候选层，不进入TPU核心库。

**Tech Stack:** Python 3.11、pandas、pytest、Ruff、Git/GitHub CLI。

## 执行结果（2026-08-31）

- 仓库基线干净，根目录保持7个业务目录和5个项目配置/说明文件；历史大文件仍隔离在原始数据归档或仓库外。
- 本地审计覆盖80个来源目录；来源级语义覆盖后识别67个来源—目标组合，其中65个已经物化，剩余2个均为阻断项：1个`blocked_data_rights`、1个`blocked_units_protocol`。精选PU泡沫已由论文方法闭合单位与协议并转入动态压缩迁移层；PUR FEA输入卡、MD分子描述符和微孔PU动态冲击均已从错误三目标中移出。
- QUB来源新增41条独立本体拉伸端点、6个同一P40试样的依赖循环代理端点、3条TGA端点及完整曲线长表。
- Data in Brief来源将975,903个原始点压缩为37次失效测试、240个依赖循环端点和12条热端点；全部置于交联PU迁移层。
- 商业TPU疲劳来源将333,492个原始点压缩为196条历史端点和6条同试样恢复配对；覆盖5个Elastollan/Texin牌号、190个独立物理试样。
- Elastollan 1154D/CAPA 6500文献表格新增3个精确质量配比的直接形状固定率与恢复率；不保存论文PDF，许可未核实时只发布数值事实与引用。
- Tecoflex EG-60D/尼可刹米来源将22,463个TGA点和1,136个拉伸点压缩为4条多性能端点；保留22个力学试样槽位汇总，排除纯药物TGA。
- IIR-OH来源将2,062,350个循环点和20,523个水解前后拉伸点压缩为600个逐循环端点及6个水解保持配对；原始文件不解包入仓库。
- TPU95A历史镜像重新物化3条载荷—伸长辅助端点与6条松弛代理端点；相对历史资产的新增科学样本贡献固定为0。
- PCF20泡沫来源将12个拉伸与6个SENB断裂试样物化为18条端点；37个物理试样不扩张成37种材料，压缩/剪切保留原始层。
- 多目标材料索引增至108个来源—材料证据行、107个唯一材料键；扩充总账增至55个包、2,591行。新增木质素/Pearlthane十个配方的8条前驱纤维力学摘要和6条TGA、未知牌号TPU三个0–100%应变实验端点和13条零权重校准仿真参考、三条鞋材商业弹性体TGA和12条耐磨摘要、导电自修复交联PU复合材料5个配方的8条拉伸/回收状态曲线和3条恢复摘要，以及4TU来源10条同试样修复配对、2条TGA端点、12条温度依赖PU泡沫动态压缩端点和79条MDPI计算描述符；碳纤维前驱体不计作TPU本体、PEBA不计作TPU、电循环不冒充机械循环、部分拉伸能量和刀切功不冒充断裂韧性，交联/泡沫体系仅作迁移，方法未闭合的仿真/MD描述符权重0。
