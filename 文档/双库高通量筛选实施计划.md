# TPU双库高通量筛选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将宽化学空间训练数据与可采购实验原料彻底分层，并建立只从现实库生成配方、再依次进入ML、DFT/MD和实验验证的可复现流水线。

**Architecture:** 虚拟库是对现有Gold-E/Gold-C/Gold-V、候选空间和量化结果的索引视图，不复制或移动冻结数据；它允许虚拟、模拟、文献和陌生结构参与表征学习。现实库只接收具有直接商业证据、明确角色和真实产品身份的构件；宏二醇按产品牌号、Mn、重复单元和批次属性管理。所有现实配方由现实构件生成，任何虚拟构件不得通过隐式连接进入实验队列。

**Tech Stack:** Python 3.12、Pandas、RDKit、YAML、pytest、现有Gold发布、采购接口证据和量化计算管线。

## 2026-08-24执行结果

- 虚拟库：7个现有事实资产索引，全部采用`reference_existing_file`，未复制Gold载荷。
- 现实库：7个商业构件、8个基础体系、32条配方、7条直接商业证据。
- PTMG代表：PTMG-1000取14个四亚甲基醚重复单元，PTMG-2000取27个；均标明单链近似且不声称产品分布。
- 现实计算任务：5个离散构件CREST/xTB、2个PTMG代表CREST/xTB、4个配方DFT闭门任务和4个块体MD闭门任务，共15条。
- 现实筛选队列：32条；ML、配方DFT和MD均按输入缺口fail-closed。
- 虚拟构件进入现实配方的泄漏数：0；Gold文件改写：false。
- 专项测试：8项通过，代码覆盖率93.75%。
- 现实构件量化输入：7/7生成三维XYZ；5个离散商用品MMFF94s收敛，2个PTMG代表显式标记为需xTB预优化。
