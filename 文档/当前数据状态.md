# TPU 数据库当前状态

**审计基准：2026-07-21。当前是多保真参考库，不是训练集。**

逐记录分层为：`Gold-E` 7,467 行、`Gold-C` 7,797 行、`Gold-E+Gold-C` 369 行、`Gold-V` 117,632 行、`Not-Gold` 68 行。这里包含 82 条来源聚合行，因此不能直接把分层行数当材料数。

科学准入状态为：正式参考 124,268 行、条件参考 8,703 行、阻断 294 行、仅证据 68 行。条件参考仍属于有价值的参考范围，但在协议、映射、权利和防泄漏门通过前，当前监督权重为 0。

## 2. Gold-C：已经有真实数值，不只是来源名称

[Gold_C_计算性能.csv.gz](../结果/Gold_C_计算性能.csv.gz) 是当前计算性能长表：

| 来源 | 数值行数 | 内容与边界 |
|---|---:|---|
| RadonPy PI1070 | 440 | 11 个明确 PU 重复单元的 DFT/MD/NEMD 等观测；保留方法、体系和性质级质量门 |
| PolyOmics | 209,905 | 3,384 条 PURT 正式参考和 3,204 条 PURA-only 条件参考所对应的非空计算性质 |
| ACS 双相演化 PU | 5 | 已发表 MD 内聚能；异常原值保留并降为条件参考 |
| OMG PhysicalProperties | 1,191,900 | 47,676 个直接计算体系×25项属性；2,086个PU体系高相关，其余为通用聚合物条件迁移 |
| Open Polymer Challenge | 4,524 | 1,649个结构的非空MD标签，空单元格不补零 |
| PUFoam | 9,014 | 1 个具有模型级实验对比证据的反应性 CFD-PBE-QMOM 2D mixing-cup 模拟；4,293 条正式参考、4,721 条条件参考，字段级准入与上限分层保存 |
| 多组分PU多尺度模拟 | 115 | 10个CG材料体系、13个不重复运行；68个组成/运行输入与47个模拟输出分角色保存，17个原表单位疑似排印错误的密度值进入条件参考 |
| 合计 | **1,415,903** | 每行有体系或结构键、性质、数值、单位状态、方法家族、保真度、来源定位、记录角色和准入状态 |

Gold-C 的方法范围现已覆盖 DFT/AIMD、GFN2-xTB、TDDFT、MD/NEMD、CGMD、CFD/PBE、FEA、COSMO-SAC 等多种保真度。长表已显式写入 `split_group`：结构型计算按规范结构族绑定，过程型计算按完整模拟体系绑定；这只是预先冻结泄漏边界，尚未生成训练/验证/测试折。PUFoam 的 0--50 s 共 51 个结果目录属于同一个独立模拟体系；9,014 行由250个源生体积平均值和8,764个可复算空间统计构成，**不是 9,014 个独立材料，也不是 9,014 次独立模拟**。其中150个单位闭合源生值和4,143个维度/语义闭合派生值进入正式参考；100个源生PBE矩与4,621个PBE矩、nodes/weights、Psi等语义未闭合派生值进入条件参考。论文中的实验对比主要支持模型层面的密度和温度表现，不能外推成全部场变量和统计量都获得逐字段实验验证。

两个来源发现 11 个重合规范结构，涉及 58 条 PolyOmics 运行；它们使用共同的结构族泄漏键，训练时必须同折。当前 `training_weight` 全为空，没有让大来源因数值多而压过实验数据。

其中 52,209 个 PolyOmics 数值的原始字段和数值可以追溯，但单位映射尚未闭合，因此全部保留为性质级 `conditional_reference`，不直接作为监督真值；补全官方单位映射后再逐性质升级，而不是删除这些计算参考。

## 4. Gold-E：高价值，但还没有完全闭环

实验侧当前物化了 [Gold_E_实验表格.csv.gz](../结果/Gold_E_实验表格.csv.gz) 的194,461个数值。原第十批包括ACS表格500个、PUE-643的`logYM/logTS/logEB`目标1,929个和无溶剂PU反应的实测`%NCO`点171个；PUE-643的20个标准化输入只作为上下文，不膨胀成性能标签。

第十一批没有再堆新目录，而是把已经完成审计但此前只有治理元数据的2,630个真实数值接入主查询表：FDM TPU晶格/基材力学1,170个、孢子填充TPU拉伸标量144个、Sheffield PU泡沫配方—反应—形貌/输运755个、SLS TPU逐试件端点375个、TPU文献力学汇总186个。36个FDM空值冲突证据仍留在审计清单，但没有伪造成数值。

第13、14、16批新增189,231条可追溯实验观测：日期籽油PU-PIR 101,645条（光谱、热分析、力学曲线和配方）、PU汽车座椅73,655条（18条IFD/松弛曲线及59个汇总指标）、再生PU泡沫13,931条（59条有效压缩曲线的0--27%区间、黏度、导热、配方和论文端点）。其中汽车座椅的松弛纵轴是未标定电压，日期籽油机械轴单位/协议未闭合，再生泡沫原始点受有效形变区间限制，因此大量记录进入条件参考而非被删除。现在Gold-E共有14,040条正式参考和180,421条条件参考；曲线点只增加观测分辨率，不增加材料体系数或训练权重。

最适合做力学曲线标定的仍是30个严格核心配方和217条键控曲线，共913,608个已审计点行。曲线点是同一试样内的相关采样，不能随机拆点当成几十万个独立样本。

第九批新增了两个重要实验参考：

- Sheffield PU 理性设计：39 个唯一泡沫配方、40 个实验批次、155 条曲线和 755 条正式或条件标量；连接配方、反应、泡孔和毛细行为。
- 糖填充超分子 PU：9 个材料条件、331 条曲线引用、115,013 个点；记录级拆分为实验、已发表连续体模型和混合叠加，不能把文件数或图层数当材料数。

这些数据可以用于实验迁移、曲线任务和机理标定，但泡沫、复合物、商业牌号和线性 TPU 核心必须保留各自适用域。

## 5. 最终可训练 Gold 还缺什么

最终一条训练记录必须通过稳定 ID 连接：

```text
组分结构/SMILES
  → 配方计量（NCO/OH、硬段、Mn/Mw/PDI）
  → 合成与加工条件
  → 实验或计算性能及协议
  → DOI、文件哈希、许可证、质量与泄漏组
```

当前最大缺口不是“数据总行数少”，而是结构—配方—工艺—性能的闭合率仍低。下一阶段应当：

1. 从 9,490 条直接构件主候选中形成满足反应规则和计量约束的完整 TPU 配方；
2. 把 Gold-C 与 Gold-E 映射到共同候选/配方 ID，按性质和来源家族校准不确定度；
3. 建立来源组级拆分与任务权重，再形成训练视图；
4. 多目标筛选到少量新体系，最后真实合成验证。

完整来源与论文引用见 [数据来源与参考文献](数据来源与参考文献.md)，详细字段和准入规则见 [Gold 数据集定义](Gold数据集定义.md)。
