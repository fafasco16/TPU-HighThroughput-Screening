# TPU 数据库当前状态

**审计基准：2026-07-21。当前是多保真参考库，不是训练集。**

逐记录分层为：`Gold-E` 7,464 行、`Gold-C` 7,795 行、`Gold-E+Gold-C` 369 行、`Gold-V` 117,632 行、`Not-Gold` 68 行。这里包含 77 条来源聚合行，因此不能直接把分层行数当材料数。

科学准入状态为：正式参考 124,263 行、条件参考 8,703 行、阻断 294 行、仅证据 68 行。条件参考仍属于有价值的参考范围，但在协议、映射、权利和防泄漏门通过前，当前监督权重为 0。

## 2. Gold-C：已经有真实数值，不只是来源名称

[Gold_C_计算性能.csv.gz](../结果/Gold_C_计算性能.csv.gz) 是当前计算性能长表：

| 来源 | 数值行数 | 内容与边界 |
|---|---:|---|
| RadonPy PI1070 | 440 | 11 个明确 PU 重复单元的 DFT/MD/NEMD 等观测；保留方法、体系和性质级质量门 |
| PolyOmics | 209,905 | 3,384 条 PURT 正式参考和 3,204 条 PURA-only 条件参考所对应的非空计算性质 |
| ACS 双相演化 PU | 5 | 已发表 MD 内聚能；异常原值保留并降为条件参考 |
| OMG PhysicalProperties | 1,191,900 | 47,676 个直接计算体系×25项属性；2,086个PU体系高相关，其余为通用聚合物条件迁移 |
| Open Polymer Challenge | 4,524 | 1,649个结构的非空MD标签，空单元格不补零 |
| 合计 | **1,406,774** | 每行有结构键、性质、数值、单位状态、方法家族、保真度、来源定位和准入状态 |

两个来源发现 11 个重合规范结构，涉及 58 条 PolyOmics 运行；它们使用共同的结构族泄漏键，训练时必须同折。当前 `training_weight` 全为空，没有让大来源因数值多而压过实验数据。

其中 52,209 个 PolyOmics 数值的原始字段和数值可以追溯，但单位映射尚未闭合，因此全部保留为性质级 `conditional_reference`，不直接作为监督真值；补全官方单位映射后再逐性质升级，而不是删除这些计算参考。

## 3. Gold-V：宽准入，但分清用途

[Gold_V_候选.csv.gz](../结果/Gold_V_候选.csv.gz) 当前有 117,629 条结构参考：

| 筛选范围 | 数量 | 用途 |
|---|---:|---|
| 直接 TPU 构件主候选 | 9,490 | 官能团约束组合、商业可得性检索、EHS 与合成路线评分 |
| OMG 虚拟 PU 重复单元 | 100,584 | 反应模板生成的候选空间；不代表实验合成成功 |
| OpenPoly 通用聚合物候选 | 3,501 | 表示迁移、相似性与主动学习；其中含PU邻域结构 |
| 混合物或盐参考 | 2,579 | 保留宽化学空间和结构证据；不计入单一可合成单体数 |
| 非合成候选 | 161 | 聚合物片段或其他参考身份；用于表示与相似性，不直接下单合成 |
| 其他相邻/前体/未决参考 | 1,314 | NIPU/TPUU 构件、聚醇前体、模型化合物及尚未分类结构 |

PolyUniverse 原始公开集有 12,072 条可靠二异氰酸酯结构参考；与现有候选按规范结构去重后，本项目新增 12,059 条，其中 9,319 条进入直接构件主候选。划分时使用 InChIKey 连接度族，而不是只按原始 SMILES，避免互变或表示差异泄漏。

## 4. Gold-E：高价值，但还没有完全闭环

实验侧当前物化了 [Gold_E_实验表格.csv.gz](../结果/Gold_E_实验表格.csv.gz) 的2,600个数值：ACS表格500个、PUE-643的`logYM/logTS/logEB`目标1,929个、无溶剂PU反应的实测`%NCO`点171个。PUE-643的20个标准化输入只作为上下文，不膨胀成性能标签；171个动力学点中169个正式参考、2个缺失时间点的记录为条件参考。

最适合做力学曲线标定的仍是30个严格核心配方和217条键控曲线，共913,608个已审计点行。曲线点是同一试样内的相关采样，不能随机拆点当成几十万个独立样本。

第九批新增了两个重要实验参考：

- Sheffield PU 理性设计：39 个唯一泡沫配方、40 个实验批次、155 条曲线和 755 条正式或条件标量；连接配方、反应、泡孔和毛细行为。
- 糖填充超分子 PU：9 个材料条件、331 条曲线引用、115,013 个点；记录级拆分为实验、已发表连续体模型和混合叠加，不能把文件数或图层数当材料数。

这些数据可以用于实验迁移、曲线任务和机理标定，但泡沫、复合物、商业牌号和线性 TPU 核心必须保留各自适用域。

## 5. 最终可训练 Gold 还缺什么

最终一条训练记录必须通过稳定 ID 连接：

```text
组分结构/SMILES
  → 配方计量（NCO/OH、硬段、Mn/Mw/PDI）
  → 合成与加工条件
  → 实验或计算性能及协议
  → DOI、文件哈希、许可证、质量与泄漏组
```

当前最大缺口不是“数据总行数少”，而是结构—配方—工艺—性能的闭合率仍低。下一阶段应当：

1. 从 9,490 条直接构件主候选中形成满足反应规则和计量约束的完整 TPU 配方；
2. 把 Gold-C 与 Gold-E 映射到共同候选/配方 ID，按性质和来源家族校准不确定度；
3. 建立来源组级拆分与任务权重，再形成训练视图；
4. 多目标筛选到少量新体系，最后真实合成验证。

完整来源与论文引用见 [数据来源与参考文献](数据来源与参考文献.md)，详细字段和准入规则见 [Gold 数据集定义](Gold数据集定义.md)。
