第19批老化植物基PU泡沫模拟原件含4,200条压缩曲线，但重复输入归并后只有3,868个唯一工况，且全部属于同一个材料家族。统一长表只保留每个唯一工况的0.1/0.5/1.0压缩对数应变应力、最大观测Mises应力和积分能量密度五个标量；曲线点不逐点灌入中心表。一个缺末端网格点的工况对应5条记录，另有6个不同工况产生完全相同数值曲线、对应30条记录；这35条均保留但降为条件参考。所有实验与模拟记录共享同族泄漏键，当前训练权重仍为空。

两个来源发现 11 个重合规范结构，涉及 58 条 PolyOmics 运行；它们使用共同的结构族泄漏键，训练时必须同折。原Gold表的`training_weight`仍全为空；可用视图通过独立性权重和任务内来源平衡采样，防止大来源仅凭数值行数压过其他来源。

其中 52,209 个 PolyOmics 数值的原始字段和数值可以追溯，但单位映射尚未闭合，因此全部保留为性质级 `conditional_reference`，不直接作为监督真值；补全官方单位映射后再逐性质升级，而不是删除这些计算参考。

[Gold_V_候选.csv.gz](../结果/Gold_V_候选.csv.gz) 当前有 117,629 条结构参考：

## 4. Gold-E：高价值，但还没有完全闭环

实验侧当前物化了 [Gold_E_实验表格.csv.gz](../结果/Gold_E_实验表格.csv.gz) 的305,108个数值。原第十批包括ACS表格500个、PUE-643的`logYM/logTS/logEB`目标1,929个和无溶剂PU反应的实测`%NCO`点171个；PUE-643的20个标准化输入只作为上下文，不膨胀成性能标签。

第十一批没有再堆新目录，而是把已经完成审计但此前只有治理元数据的2,630个真实数值接入主查询表：FDM TPU晶格/基材力学1,170个、孢子填充TPU拉伸标量144个、Sheffield PU泡沫配方—反应—形貌/输运755个、SLS TPU逐试件端点375个、TPU文献力学汇总186个。36个FDM空值冲突证据仍留在审计清单，但没有伪造成数值。

第13、14、16批新增189,231条可追溯实验观测：日期籽油PU-PIR 101,645条（光谱、热分析、力学曲线和配方）、PU汽车座椅73,655条（18条IFD/松弛曲线及59个汇总指标）、再生PU泡沫13,931条（59条有效压缩曲线的0--27%区间、黏度、导热、配方和论文端点）。其中汽车座椅的松弛纵轴是未标定电压，日期籽油机械轴单位/协议未闭合，再生泡沫原始点受有效形变区间限制，因此大量记录进入条件参考而非被删除。

第17批把已经下载并审计的低天花板TPUU原始曲线接入统一长表：4个材料代码、20条拉伸曲线和4条循环耗散曲线产生110,281个原始曲线点，并由20条拉伸曲线确定性复算峰值强度、最大观测应变和曲线积分韧性60个端点，共110,341条正式参考。另有4条DMTA曲线、2,779个点已完成来源审计，但因原件是旧版`.xls`且当前跨平台解析链尚未冻结，暂不写入Gold-E。现在Gold-E共有124,381条正式参考和180,421条条件参考；曲线点只增加观测分辨率，不增加材料体系数或训练权重。

第18批接入IIR-OH软段聚氨酯：16个配方代码、17个材料/对照身份和151条去重曲线形成3,016,301个原始信号点。为避免让高密度曲线压倒其他来源，中心Gold-E只加入306条紧凑标量：54条唯一拉伸曲线派生的162个最大观测应力、最大观测应变和记录末点前曲线面积，以及48个网络试样的144个凝胶/交联相关标量。部分曲线在仍承载时结束，因此曲线面积明确不命名为完整断裂韧性。183条进入正式参考，123条因交联密度单位未声明等原因进入条件参考。当前Gold-E合计124,564条正式参考和180,544条条件参考；完整曲线仍留在来源审计资产中。

最适合做力学曲线标定的仍是30个严格核心配方和217条键控曲线，共913,608个已审计点行。曲线点是同一试样内的相关采样，不能随机拆点当成几十万个独立样本。

当前任务化实验视图有214,704条主/辅助记录：曲线任务211,969个可用点对应181条独立曲线；标量任务2,735条可用记录对应457个独立单元和114种性质。实验硬分组由原943个`split_group`经样品/配方/曲线传递闭包收紧为818个，修复了同一试样或配方跨折的风险。

第一阶段模型基线已物化在[模型/基线结果](../模型/基线结果)：计算侧配置5个目标，其中Rg、bulk modulus、density和thermal conductivity达到严格primary训练/验证/测试门槛；Tg暂为探索目标。当前只使用加权常数与Morgan指纹Ridge作为传统基线，生成96行指标和11,694行逐样本预测。`primary_plus_aux`在内部测试集上相对常数基线有稳定改善，但可运行的来源族留出目前只有Rg/Open Polymer Challenge，且R2仍为负，因此不能把这一步写成已经得到跨来源发现模型。实验曲线端点表有201条曲线索引，其中79条通过物理端点门禁，4条循环曲线需要周期分割，20条发布层未进入模型，98条因轴语义或单位不闭合只保留血缘。

第九批新增了两个重要实验参考：

- Sheffield PU 理性设计：39 个唯一泡沫配方、40 个实验批次、155 条曲线和 755 条正式或条件标量；连接配方、反应、泡孔和毛细行为。
- 糖填充超分子 PU：9 个材料条件、331 条曲线引用、115,013 个点；记录级拆分为实验、已发表连续体模型和混合叠加，不能把文件数或图层数当材料数。

这些数据可以用于实验迁移、曲线任务和机理标定，但泡沫、复合物、商业牌号和线性 TPU 核心必须保留各自适用域。

## 5. 可用视图之后还缺什么

最终一条训练记录必须通过稳定 ID 连接：

```text
组分结构/SMILES
  → 配方计量（NCO/OH、硬段、Mn/Mw/PDI）
  → 合成与加工条件
  → 实验或计算性能及协议
  → DOI、文件哈希、许可证、质量与泄漏组
```

当前最大缺口不是“数据总行数少”，而是结构—配方—工艺—性能的闭合率仍低。下一阶段应当：

1. 从8,365个线性TPU干净构件中形成满足反应规则、计量、EHS和可采购约束的完整配方；
2. 把 Gold-C 与 Gold-E 映射到共同候选/配方 ID，优先闭合力学、热性能和耐久的结构—工艺链；
3. 以已发布硬分组、主/辅助权重和来源留出折建立第一版多任务与多保真基线；
4. 用实验残差校准不确定度，多目标筛选到少量新体系，最后真实合成验证。
