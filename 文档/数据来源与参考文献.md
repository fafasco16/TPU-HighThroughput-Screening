# TPU 数据来源与参考文献

本文件只维护可用于论文写作的来源与引用。数据规模、Gold 准入和当前缺口分别见 `结果/数据总账说明.md`、`文档/Gold数据集定义.md` 和 `文档/当前数据状态.md`。

## 1. 引用规则

- 论文 DOI 与数据 DOI 分开记录；使用具体公开数据时优先同时引用论文和数据集。
- 每个数据文件另存来源 URL、版本、访问日期、许可证和 SHA-256；引用条目不能代替文件级血缘。
- 虚拟结构必须标为 `virtual/hypothetical`，不能表述为已合成或已验证。
- DFT/MD 结果标明软件、方法、协议和目标来源，不能无标记地写成实验值。
- 许可证不明确或禁止再分发时，仓库只保存引用、哈希和获取方法，不上传原文件。
- 正式稿中使用稳定 `citation_key`；下列 Markdown 编号仅用于人工阅读。
