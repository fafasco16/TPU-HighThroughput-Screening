# TPU/TPUU 代理模型训练实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对韧性、循环恢复和热稳定三个目标分别比较小样本基线、树模型、核方法与FFNN，训练带分组验证、不确定度和适用域判定的单任务代理模型，并为当前980条现实TPU配方输出通过门禁的预测或明确的阻断状态；不生成伪预测。

**Architecture:** 先把异构曲线和端点整理为“一行一个独立监督单元”的任务表，再将二异氰酸酯、宏二醇、扩链剂和计量条件转换为共享配方特征。每个目标独立比较加权基线、ElasticNet、SVR、ExtraTrees、CatBoost、平铺FFNN和角色感知FFNN；参考论文只提供“计数Morgan＋单任务FFNN＋多种子集成”的起点，不设置复刻目标。计算数据只在受控消融中用于表示预训练、低保真辅助或残差特征，实验主目标负责最终校准。所有特征选择、调参和模型选择都嵌套在`leakage_group`与`source_family_id`分组验证内部，预测必须同时给出经组别残差校准的不确定度与适用域状态。

**Tech Stack:** Python 3.11、pandas、NumPy、RDKit、scikit-learn 1.9、CatBoost、PyTorch 2.13、Optuna、PyYAML、joblib、pytest、CSV/GZIP、SHA-256。

## 固定算法矩阵

“多训练几个”只指下表中预先登记的模型。外层测试结果出来后不得临时新增算法、修改特征或扩大超参数范围；若要新增，必须形成下一版本并重新执行全部外层分组验证。

| 层级 | 模型 | 用途 | 是否可成为正式候选模型 |
|---|---|---|---|
| B0 | 加权中位数、加权均值 | 检验复杂模型是否真正增益 | 否 |
| B1 | ElasticNet | 稀疏线性关系与可解释基线 | 是 |
| B2 | RBF-SVR | 适合独立单元较少的非线性基线 | 是 |
| B3 | ExtraTrees | 检验非平滑特征交互 | 是 |
| B4 | CatBoost | 处理数值特征、类别特征和样本权重 | 是 |
| B5 | HistGradientBoosting | 与CatBoost异构的梯度提升对照 | 是 |
| F1 | 平铺FFNN | 对多种结构/配方特征直接拼接后使用小型MLP；论文的121维计数Morgan只是候选表示之一 | 是，但必须通过严格分组门禁 |
| F2 | 角色感知FFNN | 二异氰酸酯、宏二醇、扩链剂分别编码后与配方条件融合 | 是，作为FFNN主线 |
| F3 | 迁移FFNN | 只在辅助/计算预训练相对随机初始化产生稳定外层增益时保留 | 是，失败则删除该分支 |
| S1 | PCA后GPR | 热稳定等极小样本目标的概率型诊断 | 仅诊断，除非独立单元和来源族门禁通过 |

不在V0加入GNN、Transformer、TabPFN或多任务共享主干。原因不是这些算法无效，而是当前三个目标的独立配方重叠不足；V0先回答“现有数据能否支持来源族外推”，避免将模型复杂度当成数据量。

### 预登记的搜索空间

| 模型 | 内层搜索参数 |
|---|---|
| ElasticNet | `alpha`对数均匀`1e-5–10`；`l1_ratio`取`0, 0.1, 0.25, 0.5, 0.75, 0.9, 1.0` |
| RBF-SVR | `C=1e-2–1e3`、`gamma=1e-5–1`、标准化目标空间中的`epsilon=1e-3–0.5`，均按对数尺度 |
| ExtraTrees | `n_estimators=400–1200`、`max_features=0.2–1.0`、`min_samples_leaf=1–8`、`max_depth=None或4–20` |
| CatBoost | `depth=3–8`、`learning_rate=0.005–0.1`、`l2_leaf_reg=1–50`、`iterations=300–2000`、`bagging_temperature=0–2` |
| HistGB | `max_leaf_nodes=7–31`、`learning_rate=0.01–0.1`、`l2_regularization=1e-4–20`、`min_samples_leaf=5–30` |
| GPR | 训练折内PCA保留`5–20`维或95%方差；核只比较`Matern(ν=1.5/2.5)+WhiteKernel` |
| 平铺FFNN | 特征模式`count121/role_morgan/hybrid`；2–4层；每层`16–256`且逐层不增；ReLU/SiLU；Dropout`0–0.30`；AdamW学习率`1e-5–3e-3`、权重衰减`1e-7–1e-2`、批量`8/16/32/64` |
| 角色感知FFNN | 构件编码维数`8/16/32`、融合头2–3层`32–128`、其余训练参数同平铺FFNN |

每个搜索范围都在目标标准化后解释。若某折训练样本少于批量大小，批量自动缩小到训练样本数；不得通过复制样本凑批量。Optuna优化目标为内层各折加权MAE的均值，并以最差折MAE作为并列破局指标。

### 固定特征消融

- `conditions_only`：只含硬段比例、NCO/OH、分子量与测试/工艺条件，用来检验模型是否只学到了实验协议；
- `descriptors`：三个构件的RDKit标量描述符＋条件；
- `role_morgan`：三个构件分角色计数Morgan＋条件；
- `hybrid`：计数Morgan＋RDKit描述符＋条件，作为主候选；
- `hybrid_computed`：在`hybrid`上加入能映射到训练样本和980候选的计算描述符；只在相对`hybrid`至少三分之二外层折改善且平均加权MAE改善≥5%时保留。

模型与特征模式共同在内层选择。任何来自全数据的子结构频次、PCA轴、缺失值填补或标准化参数都视为泄漏。

## FFNN三条实验线

1. **F1平铺FFNN线**：比较三种输入表示——训练折内筛选的121维计数Morgan、三个构件各512维计数Morgan的拼接、以及Morgan＋RDKit描述符＋配方条件。`34→16→8`只作为一个待比较的小网络，不被视为默认架构；宽度、深度、激活、Dropout和权重衰减都在内层验证中优化。
2. **F2角色感知主线**：三个构件各自使用512维计数Morgan与标准化RDKit描述符，经独立的`64→16`编码器压缩；与硬段比例、NCO/OH、宏二醇分子量、温度和测试协议拼接后，使用`64→32→1`回归头。宽度只在`[32, 64, 128]`，深度只在2–3层，Dropout只在`[0.0, 0.10, 0.20, 0.30]`中搜索。
3. **F3迁移线**：仅用训练折内可见的Gold-C/计算辅助性质预训练三个构件编码器，再分别微调韧性、循环恢复和热稳定单任务头。必须同时保留“随机初始化F2”对照；若F3在至少三分之二外层折中没有降低加权MAE，或降低不足5%，则F3不得进入候选集成。

FFNN统一使用PyTorch、AdamW、Huber损失、LayerNorm、早停和梯度裁剪。单次调参只训练一个种子；选定超参数后使用5个固定种子`[20260831, 20260843, 20260857, 20260869, 20260883]`重训。最终不确定度由5成员离散度与外层OOF残差的组别共形校准共同给出，不能把成员标准差直接称为置信区间。

## 各目标的模型待遇

- **韧性**：B1–B5、F1–F3全部比较；目标做`log1p`变换，主指标为反变换后的加权MAE与Spearman。
- **循环恢复**：B1–B5、F1–F3全部比较；主头只接受统一定义的弹性恢复百分比，使用`logit((y+0.5)/101)`稳定边界，报告时反变换到0–100%。
- **热稳定**：先比较ElasticNet、SVR、GPR、ExtraTrees和CatBoost；FFNN可以训练但标记为探索性。当前仅19个独立单元且来源族很少时，任何FFNN高训练集R²都不构成发布证据。

## 选模规则

- 外层：按`source_family_id`和`leakage_group`做来源族留出；另做二异氰酸酯、宏二醇、扩链剂家族冷启动压力测试。
- 内层：所有Morgan词表、缩放器、PCA、超参数搜索和早停都只拟合内层训练集。
- 折数：来源族不少于5时使用5折；2–4个来源族时采用留一来源族法；少于2个来源族时不报告来源外推指标。内层不足4个泄漏组时停用Optuna，仅运行保守默认参数并标记`insufficient_groups_for_tuning`。
- 排名：每个外层折只依据内层分组结果选模型；先满足加权MAE相对加权中位数改善至少10%，再按内层加权MAE、Spearman和区间覆盖率的预设顺序排名。外层结果只评价这套选模流程，不反向改模型；不按训练集R²选模型。
- 集成：只平均通过内层门禁且内层表现处于最佳模型一个标准误范围内的模型；禁止把所有模型无差别平均。
- 正式候选预测：必须同时通过预测性能、化学映射覆盖和适用域三道门。未通过时仍保留实验结果，但输出`blocked`而不是数值排名。

## 收到算力服务器后的调度顺序

1. **只读环境审计**：记录操作系统、CPU/内存、GPU型号与数量、显存、驱动、CUDA、PyTorch、磁盘余量和作业系统；凭据不写入仓库、日志或配置。
2. **10分钟烟雾测试**：每个目标只跑一个外层折，经典模型各1组默认参数，F1/F2各训练20个epoch；确认数据哈希、GPU可用、断点续跑和结果目录均正确。
3. **CPU基准并行**：ElasticNet、SVR、ExtraTrees、HistGB和GPR按外层折并行；单进程内部线程限制为1，防止嵌套并行抢核。CatBoost根据实测决定CPU或GPU。
4. **FFNN内层搜索**：一张GPU同一时刻只运行一个FFNN trial；多GPU时每卡一个Optuna worker。先跑F1/F2，只有F2通过直接训练门且预训练映射审计通过后才启动F3。
5. **五种子复训与外层评估**：对内层选中的FFNN配置训练5个固定种子；外层测试组只在成员全部定型后预测一次。
6. **全数据选择与候选推理**：复用完全相同的内层选择程序确定最终单模型或最多3成员的异构集成，然后预测980条现实候选。

服务器到手后先用烟雾测试实测“每trial秒数”，再生成时间预算；在未知GPU前不承诺固定小时数，也不为赶时间减少外层折或泄漏检查。

```python
def _stable_id(*values: object) -> str:
    text = "|".join("" if pd.isna(value) else str(value) for value in values)
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:24]


def _weighted_mean(group: pd.DataFrame) -> float:
    values = pd.to_numeric(group["value"], errors="coerce").to_numpy(float)
    weights = pd.to_numeric(
        group["recommended_loss_weight"], errors="coerce"
    ).fillna(0).to_numpy(float)
    valid = np.isfinite(values) & np.isfinite(weights) & (weights > 0)
    if not valid.any():
        raise ValueError("独立单元没有正权重有限目标")
    return float(np.average(values[valid], weights=weights[valid]))


def _label_rows(labels: pd.DataFrame, objective: str) -> list[dict[str, object]]:
    rule = LABEL_HEADS[objective]
    selected = labels.loc[
        labels["target_family"].eq(objective)
        & labels["property_name"].isin(rule["properties"])
    ]
    rows = []
    keys = ["independent_unit", "property_name", "unit", "method_or_test_protocol"]
    for key, unit in selected.groupby(keys, dropna=False, sort=True):
        independent, property_name, value_unit, protocol = key
        first = unit.iloc[0]
        rows.append(
            {
                "training_row_id": _stable_id(objective, "label", *key),
                "objective_id": objective,
                "target_head": rule["head"],
                "target_value": _weighted_mean(unit),
                "target_unit": value_unit,
                "protocol": protocol,
                "formulation_id": first["formulation_id"],
                "independent_unit": independent,
                "leakage_group": first["leakage_group"],
                "source_family_id": first["source_family_id"],
                "development_split": first["development_split"],
                "sample_weight": float(unit["recommended_loss_weight"].sum()),
                "source_row_count": len(unit),
                "source_row_kind": "direct_scalar",
                "condition_json": "{}",
                "chemistry_mapping_status": first["chemistry_mapping_status"],
                "chemistry_json": "{}",
            }
        )
    return rows


def _endpoint_rows(config: dict, objective: str) -> list[dict[str, object]]:
    rows = []
    for spec in config["endpoint_sources"].get(objective, []):
        source = pd.read_csv(ROOT / spec["path"], low_memory=False)
        for row in source.itertuples(index=False):
            target = getattr(row, spec["target_column"])
            independent = getattr(row, spec["independent_column"])
            group = getattr(row, spec["group_column"])
            formulation = getattr(row, spec["formulation_column"])
            conditions = {
                column: getattr(row, column) for column in spec["condition_columns"]
            }
            chemistry = {
                column: getattr(row, column) for column in spec["feature_columns"]
            }
            if pd.isna(target):
                continue
            rows.append(
                {
                    "training_row_id": _stable_id(
                        objective,
                        spec["source_family_id"],
                        independent,
                        spec["target_head"],
                        json.dumps(conditions, sort_keys=True, default=str),
                    ),
                    "objective_id": objective,
                    "target_head": spec["target_head"],
                    "target_value": float(target),
                    "target_unit": spec["target_unit"],
                    "protocol": spec["protocol"],
                    "formulation_id": formulation,
                    "independent_unit": independent,
                    "leakage_group": group,
                    "source_family_id": spec["source_family_id"],
                    "development_split": spec["development_split"],
                    "sample_weight": float(spec["weight"]),
                    "source_row_count": 1,
                    "source_row_kind": "derived_endpoint",
                    "condition_json": json.dumps(
                        conditions, ensure_ascii=False, sort_keys=True, default=str
                    ),
                    "chemistry_mapping_status": spec["chemistry_mapping_status"],
                    "chemistry_json": json.dumps(
                        chemistry, ensure_ascii=False, sort_keys=True, default=str
                    ),
                }
            )
    return rows


def build_training_tables() -> dict[str, pd.DataFrame]:
    config = yaml.safe_load(CONFIG.read_text(encoding="utf-8"))
    labels = pd.read_csv(LABELS, low_memory=False)
    labels = labels.loc[
        labels["model_ready"].fillna(False)
        & pd.to_numeric(labels["recommended_loss_weight"], errors="coerce").gt(0)
    ].copy()
    output: dict[str, pd.DataFrame] = {}
    for objective in LABEL_HEADS:
        rows = _label_rows(labels, objective)
        rows.extend(_endpoint_rows(config, objective))
        table = pd.DataFrame(rows)
        if table.empty:
            raise ValueError(f"目标没有监督端点: {objective}")
        if table["training_row_id"].duplicated().any():
            raise ValueError(f"训练行ID重复: {objective}")
        output[objective] = table.sort_values("training_row_id").reset_index(drop=True)
    return output
```

```python
@lru_cache(maxsize=4096)
def molecular_descriptors(smiles: str) -> dict[str, float]:
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        raise ValueError(f"无效SMILES: {smiles}")
    generator = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=1024)
    fingerprint = generator.GetFingerprint(mol)
    return {
        "MolWt": float(Descriptors.MolWt(mol)),
        "TPSA": float(rdMolDescriptors.CalcTPSA(mol)),
        "LogP": float(Descriptors.MolLogP(mol)),
        "HBD": float(Lipinski.NumHDonors(mol)),
        "HBA": float(Lipinski.NumHAcceptors(mol)),
        "RingCount": float(Lipinski.RingCount(mol)),
        "RotatableBonds": float(Lipinski.NumRotatableBonds(mol)),
        "FractionCSP3": float(rdMolDescriptors.CalcFractionCSP3(mol)),
        "MorganBitCount": float(fingerprint.GetNumOnBits()),
    }
```

```python
def _component_features(prefix: str, smiles: object) -> dict[str, float]:
    if pd.isna(smiles) or not str(smiles).strip():
        return {f"{prefix}_{name}": 0.0 for name in molecular_descriptors("CC")} | {
            f"{prefix}_exact_smiles_available": 0.0
        }
    return {
        f"{prefix}_{name}": value
        for name, value in molecular_descriptors(str(smiles)).items()
    } | {f"{prefix}_exact_smiles_available": 1.0}


def build_candidate_features() -> pd.DataFrame:
    candidates = pd.read_csv(CANDIDATES, low_memory=False)
    rows = []
    for row in candidates.itertuples(index=False):
        features = {
            "formulation_id": row.formulation_id,
            "macrodiol_family": row.macrodiol_name,
            "macrodiol_identity_mode": (
                "exact_smiles" if pd.notna(row.macrodiol_smiles) else "repeat_unit_and_grade"
            ),
            "macrodiol_mn": float(row.macrodiol_nominal_mn_g_mol),
            "hard_segment_fraction": float(row.hard_segment_mass_fraction_target),
            "nco_oh_ratio": float(row.nco_oh_ratio_target),
        }
        features.update(_component_features("iso", row.diisocyanate_smiles))
        features.update(_component_features("ext", row.chain_extender_smiles))
        rows.append(features)
    return pd.DataFrame(rows)


def build_training_feature_audit(
    tables: dict[str, pd.DataFrame],
) -> pd.DataFrame:
    components = pd.read_csv(COMPONENTS, low_memory=False)
    commercial_smiles = set(
        components["canonical_smiles"].dropna().astype(str)
    )
    commercial_names = set(components["preferred_name"].dropna().astype(str))
    rows = []
    for objective, table in tables.items():
        for row in table.itertuples(index=False):
            chemistry = json.loads(row.chemistry_json)
            has_iso = bool(chemistry.get("diisocyanate_smiles"))
            has_macro = bool(
                chemistry.get("macrodiol_repeat_unit_text")
                or chemistry.get("polyol_name")
            )
            has_extender = bool(
                chemistry.get("chain_extender_smiles")
                or chemistry.get("chain_extender_name")
            )
            iso_in_scope = chemistry.get("diisocyanate_smiles") in commercial_smiles
            macro_in_scope = chemistry.get("polyol_name") in commercial_names or chemistry.get(
                "macrodiol_family"
            ) in commercial_names
            extender_in_scope = chemistry.get("chain_extender_name") in commercial_names
            complete = (
                has_iso
                and has_macro
                and has_extender
                and iso_in_scope
                and macro_in_scope
                and extender_in_scope
            )
            partial = any((has_iso, has_macro, has_extender))
            status = (
                "complete_candidate_schema"
                if complete
                else "partial_transfer_schema"
                if partial
                else "source_code_only"
            )
            rows.append(
                {
                    "objective_id": objective,
                    "training_row_id": row.training_row_id,
                    "formulation_id": row.formulation_id,
                    "feature_join_status": status,
                    "candidate_model_eligible": complete,
                    "has_diisocyanate_structure": has_iso,
                    "has_macrodiol_context": has_macro,
                    "has_chain_extender_context": has_extender,
                    "diisocyanate_in_candidate_scope": iso_in_scope,
                    "macrodiol_in_candidate_scope": macro_in_scope,
                    "chain_extender_in_candidate_scope": extender_in_scope,
                }
            )
    return pd.DataFrame(rows)


def build_diagnostic_features(table: pd.DataFrame) -> pd.DataFrame:
    conditions = pd.json_normalize(
        table["condition_json"].map(json.loads)
    ).add_prefix("condition_")
    numeric_conditions = conditions.apply(pd.to_numeric, errors="coerce").fillna(0.0)
    categorical = table[
        ["formulation_id", "source_family_id", "protocol", "target_head"]
    ].fillna("missing").reset_index(drop=True)
    return pd.concat([categorical, numeric_conditions.reset_index(drop=True)], axis=1)


def build_candidate_training_features(
    table: pd.DataFrame,
) -> tuple[pd.DataFrame, pd.DataFrame]:
    if table.empty:
        return pd.DataFrame(), table.copy()
    audit = build_training_feature_audit({table.iloc[0]["objective_id"]: table})
    eligible_ids = set(
        audit.loc[audit["candidate_model_eligible"], "training_row_id"]
    )
    selected = table.loc[table["training_row_id"].isin(eligible_ids)].copy()
    components = pd.read_csv(COMPONENTS, low_memory=False)
    by_name = components.set_index("preferred_name", drop=False)
    rows = []
    for row in selected.itertuples(index=False):
        chemistry = json.loads(row.chemistry_json)
        conditions = json.loads(row.condition_json)
        iso_smiles = chemistry["diisocyanate_smiles"]
        extender_name = chemistry.get("chain_extender_name")
        extender_smiles = by_name.loc[extender_name, "canonical_smiles"]
        macro_name = chemistry.get("polyol_name") or chemistry.get("macrodiol_family")
        features = {
            "training_row_id": row.training_row_id,
            "macrodiol_family": macro_name,
            "macrodiol_identity_mode": "repeat_unit_and_grade",
            "macrodiol_mn": float(
                chemistry.get("macrodiol_nominal_mn_g_mol", 0.0)
            ),
            "hard_segment_fraction": float(
                conditions.get("hard_segment_mass_fraction", 0.0)
            ),
            "nco_oh_ratio": float(conditions.get("NCO_OH_molar_ratio", 1.0)),
        }
        features.update(_component_features("iso", iso_smiles))
        features.update(_component_features("ext", extender_smiles))
        rows.append(features)
    return pd.DataFrame(rows), selected.reset_index(drop=True)
```

```python
import pandas as pd


def source_holdout_splits(frame: pd.DataFrame, n_splits: int = 5):
    sources = sorted(frame["source_family_id"].dropna().astype(str).unique())
    if len(sources) < 2:
        raise ValueError("来源族不足，无法外推验证")
    fold_count = min(n_splits, len(sources))
    for fold in range(fold_count):
        test_sources = set(sources[fold::fold_count])
        test_mask = frame["source_family_id"].astype(str).isin(test_sources)
        yield np.flatnonzero(~test_mask.to_numpy()), np.flatnonzero(test_mask.to_numpy())


def assert_no_group_leakage(frame, train_index, test_index) -> None:
    train_groups = set(frame.iloc[train_index]["leakage_group"].astype(str))
    test_groups = set(frame.iloc[test_index]["leakage_group"].astype(str))
    overlap = train_groups & test_groups
    if overlap:
        raise AssertionError(f"发现泄漏组跨折: {sorted(overlap)[:5]}")
```

```python
import pandas as pd
from scipy.stats import spearmanr
from sklearn.metrics import mean_absolute_error, mean_squared_error


def weighted_median(values, weights):
    order = np.argsort(values)
    values = np.asarray(values)[order]
    weights = np.asarray(weights)[order]
    cutoff = weights.sum() / 2
    return float(values[np.searchsorted(np.cumsum(weights), cutoff)])


def regression_metrics(y_true, y_pred, weights):
    return {
        "weighted_mae": float(mean_absolute_error(y_true, y_pred, sample_weight=weights)),
        "weighted_rmse": float(
            mean_squared_error(y_true, y_pred, sample_weight=weights) ** 0.5
        ),
        "spearman": float(spearmanr(y_true, y_pred).statistic),
    }
```

```python
@dataclass
class Ensemble:
    members: list

    def predict(self, X: pd.DataFrame):
        values = np.vstack([member.predict(X) for member in self.members])
        return {
            "mean": values.mean(axis=0),
            "std": values.std(axis=0, ddof=1),
            "member_predictions": values,
        }


def fit_ensemble(X, y, weights, categorical, random_seed):
    categorical = list(categorical)
    numeric = [column for column in X.columns if column not in categorical]
    catboost = CatBoostRegressor(
        loss_function="RMSE",
        iterations=400,
        depth=5,
        learning_rate=0.03,
        l2_leaf_reg=5,
        random_seed=random_seed,
        verbose=False,
        allow_writing_files=False,
    )
    catboost.fit(X, y, cat_features=categorical, sample_weight=weights)
    preprocessor = ColumnTransformer(
        [
            ("categorical", OneHotEncoder(handle_unknown="ignore", sparse_output=False), categorical),
            ("numeric", "passthrough", numeric),
        ]
    )
    hist = Pipeline(
        [
            ("preprocess", preprocessor),
            (
                "model",
                HistGradientBoostingRegressor(
                    max_iter=300,
                    max_leaf_nodes=15,
                    learning_rate=0.04,
                    l2_regularization=2.0,
                    random_state=random_seed,
                ),
            ),
        ]
    )
    hist.fit(X, y, model__sample_weight=weights)
    return Ensemble([catboost, hist])
```

```python
from dataclasses import dataclass

import torch
from torch import nn


@dataclass(frozen=True)
class FFNNConfig:
    hidden_widths: tuple[int, ...]
    dropout: float
    learning_rate: float
    weight_decay: float
    batch_size: int
    max_epochs: int = 1000
    patience: int = 80


def dense_block(input_dim: int, widths: tuple[int, ...], dropout: float):
    layers: list[nn.Module] = []
    previous = input_dim
    for width in widths:
        layers.extend([
            nn.Linear(previous, width),
            nn.LayerNorm(width),
            nn.SiLU(),
            nn.Dropout(dropout),
        ])
        previous = width
    return nn.Sequential(*layers), previous


class FlatFFNN(nn.Module):
    def __init__(self, input_dim: int, config: FFNNConfig):
        super().__init__()
        self.backbone, output_dim = dense_block(
            input_dim, config.hidden_widths, config.dropout
        )
        self.head = nn.Linear(output_dim, 1)

    def forward(self, features):
        return self.head(self.backbone(features)).squeeze(-1)


class RoleAwareFFNN(nn.Module):
    def __init__(self, role_dims: tuple[int, int, int], condition_dim: int,
                 config: FFNNConfig):
        super().__init__()
        self.role_encoders = nn.ModuleList()
        for role_dim in role_dims:
            encoder, _ = dense_block(role_dim, (64, 16), config.dropout)
            self.role_encoders.append(encoder)
        self.fusion, fusion_dim = dense_block(
            16 * 3 + condition_dim, config.hidden_widths, config.dropout
        )
        self.head = nn.Linear(fusion_dim, 1)

    def forward(self, diisocyanate, macrodiol, extender, conditions):
        encoded = [
            encoder(value)
            for encoder, value in zip(
                self.role_encoders,
                (diisocyanate, macrodiol, extender),
                strict=True,
            )
        ]
        return self.head(self.fusion(torch.cat(encoded + [conditions], dim=1))).squeeze(-1)


def weighted_huber(prediction, target, sample_weight):
    per_row = nn.functional.huber_loss(prediction, target, reduction="none")
    return (per_row * sample_weight).sum() / sample_weight.sum().clamp_min(1e-12)
```

训练器必须保存最佳验证epoch、训练/验证组、特征模式、目标变换和随机种子。早停监控内层验证集的加权MAE，不监控训练损失；`transfer_ffnn`只允许加载训练折内产生的编码器权重。

```python
def evaluate_prediction_gate(
    *, model_mae, baseline_mae, median_spearman, interval_coverage,
    candidate_schema_groups
):
    improvement = (baseline_mae - model_mae) / max(baseline_mae, 1e-12)
    checks = {
        "mae_improvement": improvement >= 0.10,
        "rank_correlation": median_spearman >= 0.25,
        "interval_coverage": 0.70 <= interval_coverage <= 0.90,
        "diagnostic_chemistry_overlap": candidate_schema_groups >= 5,
    }
    diagnostic_passed = all(checks.values()) and candidate_schema_groups >= 5
    return {
        "diagnostic_passed": diagnostic_passed,
        "candidate_rank_publishable": (
            diagnostic_passed and candidate_schema_groups >= 30
        ),
        "checks": checks,
        "failed_checks": [name for name, passed in checks.items() if not passed],
        "mae_improvement_fraction": improvement,
        "candidate_schema_groups": candidate_schema_groups,
        "candidate_rank_block_reason": (
            "candidate_schema_groups_below_30"
            if candidate_schema_groups < 30
            else ""
        ),
    }
```

```python
        rows.append(
            {

```

- [ ] **Step 4A: 实现“取最好模型”与组外残差校准**

“最好”由内层分组结果预先决定：先剔除比加权中位数基线差的模型，再找到平均加权MAE最低者；处于其一个标准误范围内且Spearman不低于0.25的模型最多保留3个，按`1 / weighted_mae`归一化加权。若只有一个模型满足条件，直接使用该模型，不强制集成。

```python
from dataclasses import dataclass
import numpy as np


@dataclass(frozen=True)
class GroupConformalInterval:
    score_quantile: float
    scale_floor: float

    def interval(self, mean, std, nominal_coverage=0.80):
        scale = np.maximum(np.asarray(std, float), self.scale_floor)
        width = self.score_quantile * scale
        return np.asarray(mean) - width, np.asarray(mean) + width


def fit_group_conformal(y_true, oof_mean, oof_std, nominal_coverage=0.80):
    y_true = np.asarray(y_true, float)
    oof_mean = np.asarray(oof_mean, float)
    oof_std = np.asarray(oof_std, float)
    positive = oof_std[oof_std > 0]
    floor = max(float(np.median(positive) * 0.10) if len(positive) else 0.0, 1e-8)
    scores = np.abs(y_true - oof_mean) / np.maximum(oof_std, floor)
    level = min(1.0, np.ceil((len(scores) + 1) * nominal_coverage) / len(scores))
    return GroupConformalInterval(
        score_quantile=float(np.quantile(scores, level, method="higher")),
        scale_floor=floor,
    )
```

这里的`oof_mean/oof_std`必须来自内层“整组未见”的OOF预测，不得用训练内拟合残差。模型卡将其称为“经验组外共形区间”，不宣称在来源相关、样本量很小的情况下具有严格有限样本覆盖保证。

```python
import numpy as np
import pandas as pd


def pareto_rank(frame: pd.DataFrame, columns: list[str]) -> pd.Series:
    values = frame[columns].to_numpy(float)
    remaining = set(range(len(frame)))
    ranks = np.zeros(len(frame), dtype=int)
    rank = 1
    while remaining:
        front = []
        for index in remaining:
            dominated = any(
                np.all(values[other] >= values[index])
                and np.any(values[other] > values[index])
                for other in remaining
                if other != index
            )
            if not dominated:
                front.append(index)
        for index in front:
            ranks[index] = rank
            remaining.remove(index)
        rank += 1
    return pd.Series(ranks, index=frame.index, name="pareto_rank")
```
