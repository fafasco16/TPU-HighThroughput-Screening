# TPU商业对照生产MD预注册协议

## 1. 目的与边界

本协议预注册芳香族与脂肪族两套商业校准体系的生产MD设计，用于在真实实验前检查密度、链构象、氢键和内聚能代理是否能够稳定复现。它不授权当前立即运行MD，也不把模拟输出预先命名为实验强度、韧性或Tg。

体系固定为：

- 4,4'-MDI/PTMG-1000/1,4-BDO，目标硬段质量分数0.45、NCO/OH 1.02；
- IPDI/PTMG-1000/1,4-BDO，目标硬段质量分数0.45、NCO/OH 1.02。

每套体系3个独立重复。代理链分别为867和319个原子；为使盒规模约10,000原子，芳香族计划12条链/10,404原子，脂肪族计划32条链/10,208原子。链数只是当前代理结构的计算设计，真实PTMG批次分布闭合后必须重新核对。

## 2. 启动硬门

以下任一项缺失时只保留计划，不生成生产LAMMPS输入：

1. PTMG真实批次CoA、OH值、水分、Mn、Mw和PDI；
2. 二异氰酸酯与扩链剂批号、纯度、SDS和本单位EHS审批；
3. 全链电荷闭合、局部偶极和等价原子约束验证；
4. 氨基甲酸酯扭转候选通过独立取代片段六角度DFT/MM门；
5. 候选参数写入后的小盒能量连续性、力和角度定义测试；
6. 拟定退火温度低于真实材料TGA分解起始温度并留有明确安全裕量。

当前生产参数门为`candidate_mapped_to_twelve_chains_external_validation_pending`，因此本协议状态是`planned_not_executable_parameter_and_batch_gates`。

## 3. 暂定模拟阶段

所有时间仅用于算力预算，必须在小盒试运行后冻结：

| 阶段 | 暂定条件 | 最低输出 |
|---|---|---|
| 低密度打包 | 0.20 g cm⁻³，独立固定种子 | 初始盒、拓扑、重叠统计 |
| 能量最小化 | 分阶段软势/正式势，严格检查最大力 | 能量、最大力、终态哈希 |
| 升温 | 300 K→暂定500 K，NVT约0.5 ns | 温度、势能、链穿插异常 |
| 高温退火 | 暂定500 K，NVT约1 ns | Rg、端到端距离、氢键 |
| NPT压缩/平衡 | 暂定500 K、1 atm，不少于5 ns | 密度、体积、压力块统计 |
| 冷却 | 500 K→300 K，约2 ns；速率必须记录 | 温度—密度轨迹 |
| 300 K生产段 | 1 atm，不少于10 ns | 密度、能量、Rg、氢键、自由体积 |

暂定时间步1 fs。只有约束算法、能量守恒和温度控制通过小盒测试后才可讨论2 fs。恒温/恒压耦合常数、轨迹间隔和邻居表参数必须写入发布清单，不能依赖软件默认值。

## 4. 收敛与重复门

每个重复至少满足：

- 300 K生产段后半段密度相对时间斜率不超过0.1% ns⁻¹；
- 后半段前后两个等长区块的密度均值差不超过1%；
- 密度块均值标准误不超过1%；
- 势能、体积、Rg和端到端距离无单向漂移；
- 无异常键长、原子重叠、温压发散或SHA不闭合。

三重复只有在均通过单重复门后才计算体系均值与重复间不确定度。若其中一个失败，不删除该重复，也不只汇报另外两个；必须诊断并按预注册规则决定是否整批重跑。

## 5. 允许输出与禁用解释

参数门通过后的第一阶段只允许报告：密度、Rg、端到端距离、氢键计数/寿命代理、RDF、自由体积和内聚能密度的同协议相对比较。Tg需要独立多温度冷却协议和多重复拟合；拉伸需要尺寸/应变率敏感性与实验校准。此前396原子、1 ps、0.20 g cm⁻³结果只是执行烟雾，不能进入上述性质表。

计划表和固定种子见`计算/现实MD/商业对照MD计划/`。自动化聚合与物性定义可参考RadonPy方法[146]；LAMMPS约束与输入语义引用见[186]。完整参考文献在[数据来源与参考文献](数据来源与参考文献.md)。
