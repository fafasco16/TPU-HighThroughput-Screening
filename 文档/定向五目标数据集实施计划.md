# TPU/TPUU 定向五目标数据集实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不重写现有 Gold-V/C/E 的前提下，发布面向韧性、循环恢复、热稳定、成本和环保约束的轻量任务视图。

**Architecture:** 冻结的可用实验观测继续作为唯一性能输入；生成器只筛选目标性质、标注化学映射和监督角色，不复制无关曲线。现实构件与现实配方单独增加价格、EHS、可再生与 TPUU 路线缺口字段；成本和环保只做透明约束，不伪造监督标签。

**Tech Stack:** Python 3.11、pandas、pytest、CSV/GZIP、SHA-256 发布清单。

---

## 文件结构

- 创建 `代码/生成定向筛选数据集.py`：读取冻结输入并生成全部定向视图。
- 创建 `代码/测试/test_定向筛选数据集.py`：验证目标分类、独立配方计数、成本/EHS空缺门和确定性哈希。
- 创建 `结果/定向筛选/README.md`：解释旧数据的继续用途和新主线边界。
- 创建 `结果/定向筛选/三目标实验标签.csv.gz`：只保留韧性、循环恢复与热稳定相关记录。
- 创建 `结果/定向筛选/目标标签审计.csv`：逐性质统计行、来源、配方、曲线、独立单元和化学映射。
- 创建 `结果/定向筛选/现实构件约束.csv`：24种商用构件及价格/EHS/环保缺口。
- 创建 `结果/定向筛选/现实配方候选.csv`：980个现实组合及五目标门状态。
- 创建 `结果/定向筛选/筛选任务清单.csv`：五个目标的模型/规则类型和最低数据门。
- 创建 `结果/定向筛选/发布清单.json`：输入输出SHA-256和数量。
