# TPU 仓库清理与训练前收口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将本地工作目录和私人GitHub仓库收敛为只含可用发布数据、当前筛选代码、引用与训练前产物的浅层研究仓库，并在任何新量化计算或模型训练前停止。

**Architecture:** 清理前用远端标签冻结完整历史；新的干净分支以当前远端`main`为基线，只引入定向五目标提交。原始外部来源留在本地`数据/原始`，不上传GitHub；缓存和临时构建产物直接删除；已被可用数据集和定向视图替代的跟踪文件从当前分支删除，但可由清理前标签恢复。仓库按用户最新要求公开，第三方来源仍按各自许可证隔离。

**Tech Stack:** Git/GitHub CLI、PowerShell、Python 3.11、pandas、DuckDB、pytest、SHA-256。
