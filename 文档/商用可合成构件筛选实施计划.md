# 商用可合成构件筛选 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前宽化学空间候选与真实实验候选分层，只有身份明确、官能度正确、路线合理且具有商业目录或制造商证据的二异氰酸酯、真实宏二醇和扩链剂才能进入实验组合。

**Architecture:** 原82/86构件继续保留为模型训练和化学空间参考，不改写其量化结果。新增独立的商业证据表和fail-closed实验硬门；实验组合只从通过硬门的构件生成，并保留供应商链接、检索日期、CAS、角色、结构/产品身份以及被排除原因。PTMG等分布型宏二醇按商业产品和Mn管理，不伪造成单一小分子SMILES。

**Tech Stack:** Python 3.12、Pandas、RDKit、YAML、pytest、公开制造商/供应商目录与PubChem身份记录。

**Open interfaces selected:** PubChem PUG REST/PUG View is the primary no-key batch interface for CID, identity and dated vendor-directory hits. `mcs07/PubChemPy` (MIT) is an optional wrapper; the implementation uses the documented HTTP endpoints directly to keep dependencies small. `whitead/molbloom` (MIT) and `matteoferla/Python_SmallWorld_API` (MIT) are optional purchasability prefilters, not hard evidence because their ZINC snapshots are not live stock. eMolecules has no public unauthenticated stock API; open wrappers only construct search URLs, so it remains an optional manual/API-key adapter.
