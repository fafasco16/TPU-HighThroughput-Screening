# TPU/PU 数据库持续优化计划

**目标：** 在不创建训练集的前提下，将已完成来源审计但尚未进入统一数值视图的高价值 TPU/PU 数据逐批物化，并继续补充可追溯开放来源。

**数据流：** 原始文件保持只读；审计脚本负责冻结文件哈希、解析规则、重复与单位门禁；`代码/生成数据总账.py`只接收审计脚本输出的标准记录。Gold-E/Gold-C 继续保存科学参考身份、来源定位、泄漏组和潜在权重上限，训练划分与当前权重保持为空。

**工具：** Python 3.11、标准库 CSV/ZIP、openpyxl、PyYAML、pytest、Git/GitHub CLI。

---

## 当前优先级

1. 先接通已经下载并审计的 TPU/PU 原始数据，避免“原件很多但 Gold 视图只用了少数来源”。
2. 优先材料身份、试样、协议和单位较完整的数据；曲线点不得当作独立材料。
3. 新来源必须有稳定 DOI/版本、官方文件入口、哈希、许可证据和论文式引用。
4. 不生成训练/验证/测试划分，不物化训练权重。
