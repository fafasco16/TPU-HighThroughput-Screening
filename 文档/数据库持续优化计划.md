# TPU/PU 数据库持续优化计划

**当前目标：** 冻结现有来源规模，不再新增数据；把已完成审计的Gold-V/C/E整理成任务明确、防泄漏、带推荐权重且可直接加载的数据集，为第一版多保真模型和实验候选筛选服务。

**数据流：** 原始文件保持只读；审计脚本负责冻结文件哈希、解析规则、重复与单位门禁；`代码/生成数据总账.py`维护Gold参考层。原Gold-E/C/V的训练权重继续为空；`代码/生成可用数据集.py`在单独发布层中生成任务角色、传递闭包硬分组、固定划分和推荐权重。

**工具：** Python 3.11、标准库 CSV/ZIP、openpyxl、PyYAML、pytest、Git/GitHub CLI。

---

## 当前优先级

1. 冻结现有117,629条候选、1,435,243条计算观测和305,108条实验观测，不再扩充来源。
2. 只在任务化视图中物化训练/验证/测试划分与推荐权重，不改写Gold来源事实。
3. 曲线点、同一试样、同一配方、同一模拟和同结构跨来源记录必须通过硬分组同折。
4. 下一阶段优先闭合结构—配方—工艺—性能，并建立多任务/多保真基线，而不是继续追求行数。
