# TPU 高通量筛选数据库 v0.1 设计规范

**日期：** 2026-07-18  
**状态：** 待用户书面审阅  
**主研究路线：** 线性分段 TPU 的“时序耗散—延迟有序化”筛选，在高韧性之外同时约束滞后、循环恢复与加工窗口。  
**证据总台账：** [`TPU_数据来源与研究路线台账.md`](../TPU_数据来源与研究路线台账.md)

## 1. 决策摘要

数据库 v0.1 只解决一个边界清晰的问题：把当前已经取得的公开数据转化为**来源可追溯、许可证可审计、单位一致、可做防泄漏机器学习**的基础数据层。它不在本阶段生成虚拟单体、不运行 DFT/MD，也不宣称已经得到可合成的新体系。

推荐采用“**不可变源文件 + 分源适配器 + Parquet 规范表 + DuckDB 查询快照 + Excel 人工审核目录**”的混合架构：

- `01_原始数据/` 中的第三方文件保持只读，不重命名、不覆盖其内部结构。
- 每个来源独立抽取到 `staging`，保留原始字段、单位、sheet/文件位置和行号。
- `curated` 采用规范化长表，不把配方、试样、测试条件和曲线塞进一张宽表。
- DuckDB 是机器查询和训练快照入口；Parquet 是可版本化的交换格式。
- Excel 只作为人类审核、许可证清单和质量总览，不作为唯一数据库。

## 2. 范围与成功标准

### 2.1 本版本纳入

1. 文件级清单、SHA-256、来源 DOI/URL、许可证与再分发状态。
2. 原料/化学品、配方、合成批次、试样、测试、标量性能、曲线点和派生指标的核心表。
3. 首批代表性来源的适配：Eom 2021、Pugar 2020、预聚体黏度数据、Nature 2025 DCR、4TU SH-TPU/FDM、Jiang 2021、Li 2026，以及商业 TPU 曲线辅助层。
4. 韧性、拉伸强度、断裂伸长率、初始模量、滞后能、残余应变和循环保持率的可审计派生规则。
5. 按来源、化学体系和材料作用域生成的防泄漏分组字段。
6. 自动质量检查、许可证发布白名单和数据快照报告。

### 2.2 本版本明确不纳入

- 不把 PI1M、SMiPoly 假想结构冒充实验 TPU 数据。
- 不把 PolyOmics、ADEPT、PolyGraphMT 等计算数据与实验标签混成同一 fidelity。
- 不把商业牌号、打印几何、复合材料或交联 PUE 当作配方已知的线性 TPU。
- 不把 CC BY-NC-ND 或其他禁止演绎/再分发的数据并入可公开训练数据包。
- 不对缺失配方、缺失测试条件或扫描图数据进行无证据填补。
- 不在 v0.1 开始大规模 DFT、MD、生成模型训练或实验合成。

### 2.3 验收标准

- 100% 被纳入的原文件具有稳定 `source_file_id`、SHA-256、访问日期和许可证状态。
- 100% curated 行可以追溯到源文件、sheet/表格、原始记录或曲线文件。
- curated 表不存在孤立外键、重复主键或未知单位。
- 曲线同时保留原始数值/单位与规范数值/单位；转换规则可复算。
- 公开发布视图不包含 `reference_only`、`no_redistribution` 或许可证未知记录。
- 训练/测试分组保证同一论文、同一配方及其重复试样不会跨集合泄漏。
- 代表性曲线派生的强度、伸长率和面积与源文件/论文报告值相对差不超过 5%；数字化图源允许 10%，但必须标记 `digitized`。超限项进入异常表而不是静默覆盖。
- 同一 manifest、代码和环境锁离线重建两次时，curated/derived 快照哈希一致。

## 3. 备选架构比较

### 方案 A：单一 Excel 宽表

优点是上手快、实验人员容易编辑；缺点是无法可靠表达一对多关系、重复试样、长曲线、多 fidelity 和许可证继承，也容易产生单位与公式漂移。仅适合作为审核界面，不作为核心数据库。

### 方案 B：SQLite 规范化关系库

优点是外键和事务完整性强、单文件便携；缺点是百万级曲线点和大批量分析导出不如列式格式方便，科研人员查看原始长表也不够直接。

### 方案 C：Parquet + DuckDB + Excel 审核层（推荐）

Parquet 适合曲线长表与高通量训练，DuckDB 可以直接跨表查询并生成固定快照，Excel 提供人工审核入口。参照完整性由 schema 校验和 SQL 测试强制执行。它比单一 Excel 稳健，又比部署数据库服务器轻量，最适合当前单机科研阶段。

## 4. 文件与模块边界

```text
E:\数据\TPU\
├─ 01_原始数据\                    # 不可变来源文件
├─ 02_暂存数据\                    # 分来源忠实抽取
├─ 03_规范数据\                    # 规范化 Parquet 表
├─ 04_派生数据\                    # 曲线指标、分组与异常
├─ 05_数据库快照\                  # DuckDB 与快照元数据
├─ 06_审核导出\                    # Excel 审核目录
├─ 代码\                            # 管道模块与测试
├─ 结构定义\                        # schema、枚举和单位字典
├─ 配置\                            # 来源与管道配置
├─ 清单\                            # manifest 与快照清单
└─ 文档\                            # 设计、计划、报告和引用台账
```

每个适配器只负责“源格式 → staging”，不直接写 curated；公共规范化模块负责 staging → curated。这样修改某一个来源不会改变其他来源的处理逻辑。

实施阶段建立**只追踪代码、schema、manifest 和文档**的本地版本库，并用 `.gitignore` 排除 `01_原始数据/`、Parquet、DuckDB、审核 XLSX 及受限附件，防止约 0.60 GiB 原始数据被误提交。远程仓库使用用户授权的 GitHub 私人仓库；私人属性不改变第三方数据许可证。

## 5. 核心数据对象

| 表 | 主键 | 作用 | 必备追溯字段 |
|---|---|---|---|
| `source` | `source_id` | 论文、数据集、仓库和许可证 | DOI/URL、引用、访问日期、许可、发布限制 |
| `source_file` | `source_file_id` | 本地文件与完整性 | 相对路径、字节数、SHA-256、MIME、来源 |
| `dataset_snapshot` | `snapshot_id` | 固定输入/输出版本 | schema、代码、环境、输入/输出哈希与行数 |
| `chemical` | `chemical_id` | 原料与规范化结构 | 名称、CAS、SMILES、InChIKey、角色、官能度 |
| `material_lot` | `material_lot_id` | 批次级原料质量 | 纯度、含水量、Mn/Mw/PDI、羟值/NCO 含量 |
| `formulation` | `formulation_id` | 配方身份 | 组分、质量/摩尔/当量、NCO/OH、硬段含量 |
| `synthesis_batch` | `batch_id` | 实际制备历史 | 方法、加料顺序、温度、时间、气氛、转化率 |
| `specimen` | `specimen_id` | 试样与成型历史 | 厚度、方向、退火、调湿、老化和重复编号 |
| `test` | `test_id` | 测试条件 | 标准、仪器、模式、温湿度、速率、频率、循环 |
| `property_value` | `property_id` | 标量或统计性能 | 原始值/单位、规范值/单位、误差、fidelity |
| `curve` | `curve_id` | 曲线元信息 | 曲线类型、轴定义、阶段、循环、原始文件 |
| `curve_point` | (`curve_id`,`point_index`) | 有序长表曲线点 | 原始 x/y、规范 x/y、时间/温度/循环索引 |
| `derived_property` | `derived_id` | 可复算曲线指标 | 算法版本、参数、输入曲线、值、单位、不确定度 |
| `computation` | `computation_id` | 后续 DFT/MD 记录 | 软件/版本、方法、力场、模型和收敛状态 |
| `prediction` | `prediction_id` | 后续模型输出 | 模型/数据快照、均值、不确定度、适用域与排名 |

配方组分使用独立桥接表 `formulation_component`，避免为“polyol_1、polyol_2、chain_extender_1”不断增加列。

## 6. ID、单位与证据约定

### 6.1 稳定 ID

- 数据集：`ds_<来源简称>_<年份>`，例如 `ds_eom_2021`。
- 文件：对规范化相对路径和 SHA-256 生成稳定 ID。
- 源内记录：保留论文样品名，同时生成独立 `formulation_id`/`specimen_id`。
- 同一配方的重复、不同测试条件和循环曲线必须拥有不同 `specimen_id` 或 `test_id`，不能覆盖。

### 6.2 原始值与规范值并存

- 应力：规范为 `MPa`。
- 应变：规范为无量纲 `1`，同时保存原始 `%`。
- 温度：规范为 `K`，审核导出增加摄氏度显示列。
- 黏度：规范为 `Pa·s`。
- 时间：规范为 `s`；频率为 `Hz`。
- 韧性/滞后能密度：当应力为 MPa、应变无量纲时，规范为 `MJ·m^-3`。

任何无法可靠判断的单位标记为 `unit_status=unresolved` 并阻止进入训练视图。

### 6.3 证据等级

- `measured_raw`：作者公开的逐点原始数据。
- `measured_summary`：作者表格中的统计值。
- `digitized`：从图中数字化；必须记录图号、工具和误差。
- `derived`：由本项目从原始曲线计算。
- `computed_dft`、`computed_md`、`predicted`：各自保持独立 fidelity。

## 7. 数据分层和首批来源

| 层级 | 首批来源 | 在 v0.1 中的角色 |
|---|---|---|
| 主化学/配方层 | Eom 2021、Pugar 2020、预聚体黏度数据 | 建立线性 TPU/PUE 的结构、配方、Tg 与加工先验 |
| 机制与多模态层 | Nature 2025 DCR、TPU 氢键数据 | 标定结晶/氢键/温度依赖机制；材料边界单独标记 |
| 曲线与循环层 | 4TU SH-TPU、Jiang 2021、Li 2026、Schwarz 2022 | 学习曲线表示、滞后、恢复、环境和速率效应；不冒充线性 TPU 配方标签 |
| 商业/打印外部验证 | TPU95A、Zenodo 4156000、Zenodo 15490464 | 测试条件和几何域迁移、外部鲁棒性，不用于单体逆向设计 |
| 通用低 fidelity | OpenPoly、PolyOmics、ADEPT、PolyGraphMT | 后续预训练/描述符先验，与实验表严格分层 |
| 候选结构种子 | SMiPoly、PI1M | 后续反应约束候选生成；v0.1 不赋予实验性能标签 |
| `reference_only` | DiMPU 2025、PUN 2026 等限制性数据 | 内部机制比较，禁止进入公开衍生训练包 |

ScienceDB `datasets.csv`、Ding 529 曲线与 PUE-643 原始数据在获作者授权并完成哈希/许可审计后，作为独立增量版本加入，不阻塞 v0.1。

首个端到端垂直切片只打通四种不同数据形态，验证架构后再扩展：`smipoly_monomers.csv` 验证化学品与角色，DQ 的 PUE 326 行基准验证标量性能与数据谱系，`TPU_HBond_2021_Source_Main.xlsx` 验证测试—曲线—派生性能，预聚体 `ViscTempData.xlsx` 验证温度—黏度加工曲线。PI1M 和大型 PolyOmics 在 v0.1 仅登记 manifest 并做流式 schema/QC 抽样，不进入首轮全量转换。

## 8. 曲线处理与派生规则

1. 保留原始点顺序；禁止为了“好看”自动平滑或删除异常点。
2. 单调拉伸曲线允许按明确规则去除仪器前导空行，但必须记录截断索引。
3. 循环曲线先按循环号或载荷方向分段，再计算加载面积、卸载面积、滞后能和残余应变。
4. 韧性使用梯形积分：

   \[
   U_T=\int_0^{\varepsilon_b}\sigma(\varepsilon)\,\mathrm d\varepsilon
   \]

5. 初始模量必须保存拟合应变窗口、拟合方法和拟合优度，不能只存一个数字。
6. 从曲线得到的强度、断裂伸长率和已发表汇总值同时保留，并记录差值。
7. 原始曲线不含试样截面积或标距时，不得把力—位移擅自转换为应力—应变。

## 9. 防泄漏与机器学习就绪性

每条记录生成以下分组：

- `source_group`：论文/数据集级。
- `formulation_group`：相同组分与比例级。
- `chemistry_group`：软段—二异氰酸酯—扩链剂家族级。
- `specimen_group`：重复试样级。
- `material_scope`：线性 TPU、交联 PUE/WPU、商业 TPU、复合材料、光固化弹性体等。

首个基线必须至少报告随机拆分、按来源留一和按化学家族留一三种结果。论文主结论不得只引用随机拆分分数。

MatImpute 中按字段和缺失率生成的多份 PUE 文件来自同一 326 行母数据，不能计作新增样本；DQ、MatImpute、PUE-643、386 条清洗曲线和 326 条变换基准必须共享谱系/样品家族分组。任何由同一母数据派生的缺失版本都必须锁定在同一拆分侧。

## 10. 许可证与发布门控

每个来源明确：`license_spdx`、`commercial_use`、`derivatives_allowed`、`redistribution_allowed`、`attribution_text` 和 `access_restriction`。

发布视图采用白名单：只有许可证明确允许演绎与再分发、且追溯字段完整的记录才进入。未知许可证默认拒绝发布；CC BY-NC-ND 数据仅存 `reference_only` 来源元数据和引用，不复制内容或可逆派生数据到发布包。

3. `03_规范数据/*.parquet`：规范化核心表。

6. `文档/质量报告/v0.1质量报告.md`：缺失、单位、重复、泄漏、许可证和适用域报告。
7. `文档/质量报告/v0.1数据集说明.md`：论文写作可复用的数据说明与正式引用。

## 12. 后续子项目边界

数据库 v0.1 通过验收后再依次启动：

1. **ML 基线与适用域**：标量多任务模型、曲线表征与校准不确定度。
2. **反应约束候选生成**：固定 1–2 种软段和 1–2 种二异氰酸酯，优先搜索可购双官能扩链剂/共扩链剂。
3. **DFT/MD 多保真闭环**：只计算合成可行且信息增益高的候选，提取竞争氢键、构象、相分离与链段动力学指标。
4. **实验验证**：第一轮 8–12 个信息增益样品，第二轮 3–6 个主动学习增量；保留失败与不可加工结果。
5. **逐候选新颖性档案**：论文、专利、供应商和结构相似性检索在最终合成前完成。
