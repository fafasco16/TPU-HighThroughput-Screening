# TPU/TPUU 本地来源审计与定向扩库实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先盘清本地原始来源中尚未用于韧性、循环恢复和热稳定模型的数据，再按缺口持续接入公开来源并维护引用与许可证。

**Architecture:** 审计器只读取`数据/原始/外部数据/新增开放数据`，扫描文件名、CSV表头、XLSX工作表名和ZIP成员名，不修改原件。结果按来源和目标生成优先级队列；后续每个来源通过独立适配器增量物化到定向发布层，禁止把曲线点、试样重复或计算工况扩张成新材料数。

**Tech Stack:** Python 3.12、pandas、zipfile、openpyxl、pytest、CSV/Markdown、SHA-256。

- [ ] **Step 1: 按缺口生成三组检索式**

```text
TPU OR TPUU + stress-strain raw data + formulation
TPU OR TPUU + cyclic loading unloading + residual strain/recovery + data
TPU OR TPUU + TGA raw data + formulation + supporting information
```

- [ ] **Step 2: 优先数据仓库和作者SI**

检索顺序为机构/期刊SI、Zenodo、Figshare、Mendeley Data、ScienceDB、DRUM和固定GitHub发布；搜索结果页或二手汇总不能作为数值来源。

- [ ] **Step 3: 许可证和引用门**

公开GitHub只接入允许再分发的派生数据；`CC BY-NC`、仅供请求或许可不明来源保留本地引用和处理代码，不上传受限原件。

- [ ] **Step 4: 达标停止扩库**

每个目标达到最低完整化学映射数后停止泛搜：韧性80、循环恢复60、热稳定80。之后只补化学空间缺口、独立外部测试集和现实TPUU胺类路线。
