# TPU 数据库 v0.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` when available. This environment does not expose that skill, so use the built-in multi-agent delegation tools, keep file scopes disjoint, and have the primary agent review, test, and commit each integration point. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改写原始文件的前提下，建立来源可追溯、许可证可门控、能处理标量与曲线数据的 TPU 数据库 v0.1，并推送至用户 GitHub 账户下的私人仓库。

**Status:** 已完成。中文浅层结构、四源端到端管道、质量门、审核工作簿和 GitHub 私人仓库均已验收；本地 `main` 与远端 `main` 同步。

**Architecture:** `01_原始数据/` 是不可变来源区，`02_暂存数据/`、`03_规范数据/`、`04_派生数据/` 分别承载忠实抽取、规范化表和派生结果；原始文件不纳入 Git。Python 管道负责 manifest、单位、曲线、适配器、QC 与 Parquet/DuckDB 快照；`@oai/artifact-tool` 负责生成 Excel 审核目录。首轮用四个垂直切片验证 chemical、property、curve 和 processing-curve 路径。

**Tech Stack:** Python 3.11、pandas、pyarrow、duckdb、openpyxl、PyYAML、pytest、pytest-cov；Node.js、`@oai/artifact-tool`；Git、GitHub CLI。

`代码/ids.py`:

```python
import hashlib
import json

def stable_id(namespace: str, *parts: object) -> str:
    payload = json.dumps(parts, ensure_ascii=False, separators=(",", ":"), sort_keys=True)
    digest = hashlib.sha256(payload.encode("utf-8")).hexdigest()[:16]
    return f"{namespace}_{digest}"
```

`代码/licensing.py`:

```python
def may_publish(license_spdx: str, derivatives_allowed: bool | None,
                redistribution_allowed: bool | None) -> bool:
    return bool(
        license_spdx not in {"", "UNKNOWN", "NOASSERTION"}
        and derivatives_allowed is True
        and redistribution_allowed is True
        and "-ND-" not in license_spdx
    )
```
