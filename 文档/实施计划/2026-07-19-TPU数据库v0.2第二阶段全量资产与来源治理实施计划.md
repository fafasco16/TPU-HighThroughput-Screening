# TPU 数据库 v0.2 第二阶段：全量资产与来源治理实施计划

> 状态：治理构建可复现性门已通过。2026-07-20 两次真实隔离构建的 11 个产物全部字节一致；本阶段仍只登记、治理和审计现有数据资产，不构建训练集，不训练模型，不覆盖 v0.1 冻结快照。

规范性依据为[《TPU 数据库 v0.2 多保真设计规范》](../设计规范/2026-07-19-TPU数据库v0.2多保真设计规范.md)，来源书目和引用键以[《TPU 高通量筛选：数据来源、证据等级与研究路线台账》](../TPU_数据来源与研究路线台账.md)为唯一主台账。

## 1. 阶段目标

把 `01_原始数据` 的动态发现集合完整转换成可复算的资产登记、来源范围、文件身份、精确重复关系、角色决定、生命周期状态、引用和权利证据候选，使实验、DFT、MD、候选结构、代码、文献附件和受限参考材料都“有身份、有来源、有角色、有状态、有去重边界”。

本阶段解决“磁盘上文件很多但正式入库来源很少”的治理缺口，不以放宽证据标准换取表面数据量。计算数据可以登记和进入后续计算观测层，但不得冒充实验标签；CSV 行、曲线点、模拟帧、缺失率变体、镜像文件和子集视图不得增加独立配方数。

## 2. 不可违反的边界

- 不修改、重命名或删除 `01_原始数据` 中的第三方文件。
- 不运行现有原位写入的 v0.1 `build/qc` 命令；在隔离输出根实现前，不覆盖 `02_暂存数据`、`03_规范数据`、`04_派生数据`、`05_数据库快照` 和既有质量报告。
- 不把 `publisher_claim`、`repository_metadata` 或 `temporary_file_audit` 写成冻结数据库计数；只有文件落地、哈希固定、解析与去重规则绑定后的 `ingested_file_recount` 才可成为冻结事实。
- 不从论文许可自动推断数据文件许可，不从公开可访问推断允许训练或再分发；未知、范围未决、冲突、撤回和作者授权要求均按动作 fail closed。
- 不建立训练/验证分区，不设置训练权重，不生成模型性能或候选排名。
- 所有输出先标记为 `provisional`；只有本计划全部门通过后，才可提交下一阶段冻结评审。

## 5. Task 2：冻结动态发现与分类规则

`v0.2资产登记规则.yaml` 必须版本化保存：

- 扫描根、是否跟随符号链接、必须剪枝的 `.git` 目录、路径编码和排序规则；
- 路径/扩展名/文件名匹配规则、显式优先级和冲突处理；
- `artifact_role`、`data_stage`、非权威 `material_scope_hint`、`source_family_key`、`source_scope_key`、初始六状态和决定依据；
- 机器规则、人工核验和证据排除的区别；
- 精确哈希重复的规范成员选择规则；
- 未匹配、同优先级冲突、路径逃逸、符号链接和读取失败的 blocking 处理。

配置必须覆盖当前五类一级路径：`基础数据`、`代码仓库镜像`、`外部数据`、`仅供参考` 和根 README；发现数量是动态结果，禁止在代码中硬编码 1,607。

## 6. Task 3：TDD 实现全量资产登记

### 6.1 稳定身份

每个资产至少保存：

- `asset_occurrence_uid`：发现范围与规范相对路径的 UUIDv5；
- `source_file_uid`：来源范围与来源文件自然键的 UUIDv5；
- `content_blob_uid`：SHA-256 内容身份；
- `record_revision_id`：内容和分类元数据的不可变修订身份；
- 相对 POSIX 路径、原文件名、扩展名、字节数、SHA-256、媒体类型和读取状态。

绝对路径、扫描时间和快照不得进入稳定 UID。路径变更可改变 occurrence，但不得改变相同内容的 blob 身份；同内容出现在不同来源范围时保留不同 source file 身份并共享 blob 身份。

### 6.2 规则执行

- [ ] 路径统一 Unicode NFC 和 `/` 分隔符，按 casefold 后的规范路径稳定排序。
- [ ] 流式计算 SHA-256，不一次性读入大文件。
- [ ] 每个文件恰好获得一个最高优先级分类决定；同优先级冲突立即失败。
- [ ] 每行保存匹配规则 ID、规则版本、决定方式、置信状态和复审要求。
- [ ] 六组生命周期状态独立保存，禁止把 availability 当 registration 或 scientific admission。
- [ ] 输出 CSV 使用固定列顺序、UTF-8 BOM 和稳定换行；相同输入两次生成字节一致。
