# TPU/TPUU 多目标高通量筛选

本仓库面向可实际采购和合成的 TPU/TPUU 体系，联合考虑韧性、循环恢复、热稳定、成本与环保属性。实验、计算和迁移数据分层保存；模拟值、曲线点和工艺条件不会冒充独立材料或实验真值。

## 当前状态

- 受治理扩充包：67个、16,977条紧凑记录；
- 三目标实验标签：120,550条；目标相关计算证据：49,085条；
- 多目标材料索引：124条来源—材料证据、123个唯一材料键；
- 现实候选：24种商用构件、980个可合成导向配方；
- 代理训练入口已发布，实际模型权重和新DFT/MD尚未产生。

## 使用边界

- 韧性、循环恢复和热稳定分别训练单任务代理；成本和环保采用透明规则约束，不伪造机器学习标签。
- `development_split`和`leakage_group`是固定防泄漏划分，禁止对曲线点逐行随机切分。
- Gold-C只用于表示预训练、低保真辅助、机理特征或同体系工况代理。
- 泡沫、交联网络、SHPU等迁移层不能抬高线性TPU核心配方数量。
- 目录/供应商证据不等于实时库存、报价或已完成SDS审查。

## 重建与检查

```powershell
uv sync --extra dev
uv run python 代码\生成定向筛选数据集.py
uv run python 代码\生成代理模型训练输入.py
uv run pytest 代码\测试 -q
uv run ruff check 代码
```

发布清单记录输入输出SHA-256。GitHub仓库公开发布，但第三方数据仍按各自许可证和引用要求使用；本仓库版权说明不覆盖第三方来源权利。
