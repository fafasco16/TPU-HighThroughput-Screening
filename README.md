# TPU 高通量筛选数据库

本项目用于发现并实验验证新的高性能 TPU/TPUU 体系。数据库采用多保真路线：实验、DFT/AIMD、MD/NEMD、CGMD、CFD/PBE、FEA 等计算模拟和来源可靠的虚拟候选都可以进入参考范围，但必须保留数据身份、方法、条件、来源和可信度，不能把模拟或预测值写成实验真值。

## 现在有什么

| 数据层 | 当前规模 | 含义 |
|---|---:|---|
| 来源范围 | 82 | 81 个独立来源贡献；同一论文、数据集和附件按来源家族防重复 |
| `Gold-E` 实验观测 | 194,461 条 | 14个来源家族的原始曲线点、逐试样端点、配方、工艺、动力学和实验汇总值；14,040条正式参考、180,421条条件参考 |
| `Gold-C` 计算数值 | 1,415,903 条 | 可靠 DFT/AIMD、GFN2-xTB、TDDFT、MD/NEMD、CGMD、CFD/PBE、FEA、COSMO-SAC 等直接或可复算结果及明确标注的计算上下文 |
| `Gold-V` 结构参考 | 117,629 条 | 构件、规则生成 PU 重复单元和通用聚合物候选；全部保留虚拟身份 |
| 全部逐记录清单 | 133,333 行 | 来源、候选、试件、运行、曲线、标量和证据的合计，不等于独立材料数；高密度曲线点另存于Gold-E长表 |
| 当前模型就绪记录 | **0** | 尚未建立训练划分，也没有物化逐条训练权重 |

`Gold` 在这里表示“值得保留并可追溯的科学参考”，不等于所有数据都能同权训练。来源可靠但协议、适用域或实验映射暂不完整的数据进入 `conditional_reference`；缺什么就限制对应任务，不再整源删除。

## 最终 Gold 由什么组成

最终不是一张只有 SMILES 和拉伸强度的表，而是五类信息通过稳定 ID 连接：

1. 候选结构：组分 SMILES、规范 SMILES、InChIKey、官能度、候选角色和生成规则；
2. 配方计量：异氰酸酯、多元醇、扩链剂、NCO/OH、硬段含量、Mn/Mw/PDI 和添加剂；
3. 合成与加工：路线、催化剂、温度、时间、含水量、退火及成型条件；
4. 性能与条件：实验、DFT、MD 或预测数值，以及单位、温度、应变率、方法和不确定度；
5. 血缘与质量：DOI/URL、版本、文件哈希、许可证、Gold 层、准入状态、泄漏组和未来权重上限。

这五块闭合后才能形成真正可训练的一行。现阶段的 117,629 个结构参考不等于 117,629 套完整 TPU 配方，1,415,903 个计算数值也不等于同等数量的独立模拟或实验。PUFoam 的 9,014 行由同一个 2D mixing-cup 反应性发泡模拟产生；第15批多尺度模拟的115个数值中，47个是计算输出、68个是组成或运行输入。它们都保留，但输入不会被混算成性能标签。

## 先看这六个文件

1. [当前数据状态](文档/当前数据状态.md)：当前数量、用途和缺口；
2. [Gold 数据集定义](文档/Gold数据集定义.md)：字段、准入和多保真权重原则；
3. [数据规模总账](结果/数据规模总账.csv)：逐来源机器可读汇总；
4. [Gold-V 候选](结果/Gold_V_候选.csv.gz)：117,629 条结构级参考；
5. [Gold-C 计算性能](结果/Gold_C_计算性能.csv.gz)：1,415,903 条计算输出或明确标注的计算上下文长表；
6. [Gold-E 实验表格](结果/Gold_E_实验表格.csv.gz)：194,461 条曲线点、实验目标、逐试样端点、配方/工艺观测或动力学值。

完整逐记录审计在 `结果/样本清单.csv.gz`。论文式数据引用统一维护在 [数据来源与参考文献](文档/数据来源与参考文献.md)。

`配置/清单/来源清单.csv` 只保留给旧 v0.1 四源管道兼容；当前多保真数据库的权威清单是 `结果/数据规模总账.csv` 和 `结果/样本清单.csv.gz`，不要把两套口径混用。

## 目录

```text
数据/       本地原始与中间数据；大文件不上传 GitHub
代码/       来源审计、总账生成和测试
配置/       来源、权利、准入和资产规则
文档/       Gold 定义、当前状态、数据来源与参考文献
结果/       可查询的轻量总账和 Gold 视图
```

GitHub 私人仓库只保存代码、配置、文档和必要结果，不上传出版商附件、受限原件或可从 DOI 恢复的大型原始文件。

## 运行

```powershell
uv sync --extra dev
uv run python 代码\生成数据总账.py
uv run pytest 代码\测试 -q
```

当前版本只建立可复核的数据参考层；训练开关、数据划分和逐条训练权重保持关闭。
