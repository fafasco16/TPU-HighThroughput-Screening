# TPU/TPUU 多目标高通量筛选

本仓库面向可实际采购和合成的 TPU/TPUU 体系，目标是联合筛选韧性、循环恢复、热稳定、成本与环保属性。当前阶段只整理数据、配方和训练输入，不运行新的 DFT/MD，也不训练最终模型。

## 当前主线

三个性质分别建立单任务、多保真模型：

1. 韧性：以应力—应变曲线积分面积为主目标；
2. 循环恢复：以固定应变和循环数下的残余应变/弹性恢复率为主目标；
3. 热稳定：以 T5、T10 或 Td,onset 为主目标，Tg 单列为使用温度辅助指标。

成本与环保不伪造成机器学习标签。成本由配方质量分数和同地区、同日期报价计算；环保保留可再生碳、GHS/SDS、溶剂/催化剂、工艺能耗和回收证据等透明子指标。

计算数据按四种角色使用：直接低保真标签、迁移预训练、机理特征和同体系工况代理。模拟或代理值始终保留方法和保真度，不冒充实验真值。

## 重建与检查

```powershell
uv sync --extra dev
uv run python 代码\生成定向筛选数据集.py
uv run python 代码\生成定向筛选数据集.py --检查
uv run pytest 代码\测试 -q
uv run ruff check 代码
```

`结果/定向筛选/发布清单.json`记录输入输出 SHA-256。GitHub仓库公开发布，但第三方数据仍按各自许可证和引用要求使用；本仓库版权说明不覆盖第三方来源权利。
