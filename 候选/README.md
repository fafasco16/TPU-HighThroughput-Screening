# 现实候选

当前只保留与实验路线直接相关的候选文件：

- `商用构件证据.csv`：24种具有制造商或目录证据的构件；
- `实验合理组合.csv`：980个计量闭合的现实TPU配方；
- `采购接口证据.csv`与`采购接口运行清单.json`：目录信号及查询血缘；
- `商用构件证据说明.md`：采购证据的解释边界。

目录命中不代表实时库存、价格有效或本单位EHS批准。所有价格、SDS、CoA、含水量和羟值在证据闭合前保持缺失或阻断状态。

当前扩链剂均为二醇，因此980个配方属于TPU候选，不代表TPUU空间。TPUU必须先增加商业二胺/胺类扩链剂及对应的脲键结构和反应规则。

旧虚拟构件、DFT队列和中间预审表已由发布数据替代，可从Git标签`pre-cleanup-20260830`恢复。
