# 商用构件与采购查询接口说明

## 采用的查询层级

商业可得性分四级记录，低级证据不能自动升级为实验放行：

1. **结构身份**：RDKit规范结构、InChIKey和PubChem CID；
2. **目录预筛**：PubChem PUG View的`Chemical Vendors`类别；
3. **直接商业证据**：制造商产品页或供应商目录页，记录检索日期、CAS或产品牌号；
4. **采购放行**：国内/本地报价、当前库存、COA、SDS和本单位EHS批准。该级必须人工完成。

`代码/商用构件筛选.py --查询PubChem`实现前两级。接口不需要API密钥，查询结果写入`当前82构件采购查询.csv`，包括CID、供应商目录记录数、去重供应商名称、状态和UTC查询时间。PubChem供应商目录记录可能过期、重复或只支持定制合成，因此只能记作`catalog_index_hit`。

## GitHub开源项目评估

| 项目 | 许可证/状态 | 能力 | 本项目决定 |
|---|---|---|---|
| [mcs07/PubChemPy](https://github.com/mcs07/PubChemPy) | MIT；非归档 | PubChem PUG REST的Python封装 | 可选依赖；当前直接调用官方HTTP接口，减少依赖 |
| [whitead/molbloom](https://github.com/whitead/molbloom) | MIT；活跃 | 用ZINC20目录Bloom filter快速判断是否可能可购买 | 可作离线预筛；目录快照和Bloom假阳性使其不能作为硬门 |
| [matteoferla/Python_SmallWorld_API](https://github.com/matteoferla/Python_SmallWorld_API) | MIT；非官方 | 查询ZINC/SmallWorld的在售或按需合成空间 | 可作相似可购替代物搜索；不用于批量重压公共服务 |
| [thejameshoward/CommercialCompoundSearcher](https://github.com/thejameshoward/CommercialCompoundSearcher) | 仓库未声明许可证 | 从SMILES查询PubChem CID和供应商类别 | 思路吻合，但未复制其代码；本项目自行实现并测试 |
| [mims-harvard/ToolUniverse](https://github.com/mims-harvard/ToolUniverse) 的eMolecules工具 | Apache-2.0 | 生成eMolecules名称/SMILES搜索链接 | eMolecules没有公开无密钥库存API；仅保留为人工搜索入口 |

最稳妥的自动流程是“PubChem目录预筛 → 官方厂家页/供应商目录核验 → 人工询价/SDS”。任何脚本都不能承诺某地区、某时点一定有库存。

## 统一适配层运行状态

`代码/采购接口.py`和`代码/查询构件采购.py`现已把接口统一到同一证据结构，并启用缓存、限速、哈希清单和fail-closed聚合：

- PubChem：82条均有查询记录，78条完成、4条未找到；
- molbloom 3.2.0：在Ubuntu/Linux隔离子进程中完成82条`zinc-instock-mini`查询；
- eMolecules：为82条结构生成精确搜索链接，但不计入目录命中；
- SmallWorld API 1.1.4：已接入并测试，批量默认关闭，只允许通过`--启用SmallWorld`对配置中的最多8条短名单限速查询。

SmallWorld实网烟雾测试使用1,4-BDO结构`OCCCCO`，当前ZINC数据集返回1条`dist=0`精确命中；适配器会丢弃接口同时返回的`dist>0`相似物，避免把相似结构误报成同一商品。

完整`zinc-instock`过滤器托管在Dropbox，当前Windows网络无法下载；因此本轮使用随包附带的mini过滤器。mini过滤器假阳性率约7%，其命中只能作为弱信号。molbloom Windows C扩展还会导致进程级崩溃，所以适配器固定在隔离子进程中执行；正式82条结果来自Ubuntu/Linux，避免影响主筛选进程。

统一证据共246行（82×3个已运行接口）。聚合后：22条有两个目录信号、16条有一个信号、44条无目录信号。两个虚拟二异氰酸酯仅被mini Bloom filter命中、PubChem供应商为零，考虑较高假阳性率后仍保持阻断。

## 当前82构件查询结论

- 查询总数：82；
- PubChem身份和供应商查询完成：78；PubChem未找到：4；
- 存在供应商目录记录：36；无供应商目录记录：42；
- 扩链剂：22/22有目录记录；
- 宏二醇结构代理：14/14有目录记录，但都是小分子，不能因此冒充真实商业宏二醇；
- 二异氰酸酯：46个中0个有供应商目录记录，42个能解析到PubChem但没有供应商类别，4个PubChem未找到。

这解释了为什么原阶段代表中有许多陌生结构：二异氰酸酯来自虚拟结构空间而非商业原料目录。原82构件继续保留用于模型与量化参考，但当前没有一个三组分组合能通过新的实验硬门。
