# 代码目录

代码按职责而不是来源层级组织，避免继续增加子目录。

## 主入口

1. `生成定向筛选数据集.py`：重建三目标标签、计算证据、现实配方和总说明；
2. `生成多目标材料索引.py`：按来源与材料键汇总目标覆盖；
3. `生成扩充数据总账.py`：汇总全部受治理扩充包；
4. `生成代理模型训练输入.py`：生成训练统计、来源映射和使用说明；
5. `审计本地目标来源.py`：只读审计本地原件并更新扩库队列；
6. `生成三目标配方特征.py`：生成980个现实配方的训练前特征。

## 其他文件

- `接入*.py`：一项开放来源对应一个确定性适配器；
- `提取*.py`：从曲线中生成统一端点；
- `采购接口.py`、`查询构件采购.py`：采购证据接口；
- `配方系综特征.py`：配方和构象特征工具；
- `测试/`：适配器、数量门、哈希和发布清单回归测试。

## 常用检查

```powershell
uv run python 代码\生成定向筛选数据集.py --检查
uv run python 代码\生成多目标材料索引.py --检查
uv run python 代码\生成扩充数据总账.py --检查
uv run python 代码\生成代理模型训练输入.py --检查
uv run pytest 代码\测试 -q
uv run ruff check 代码
```

原始数据保持只读；新增来源必须同时提供适配器、发布清单、测试和参考文献记录。
